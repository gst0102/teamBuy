运营规则

先看状态，再换群码

  • 02落地页显示已上传的真实群头像、群名和当前内层群码；微信里长按内层群码选择“识别图中二维码”。
  • 03列表里的“已过期 / 1 天内到期”针对当前群二维码目标，不代表外层活码失效。
  • 04群码过期后落地页会提示更新；暂停会保留访问次数，恢复后继续使用最近群码。
  • 05访问次数是入口请求次数，不是去重人数；后续如需渠道归因，再单独增加渠道字段。
  • 06群人数检测暂未启用；后续接入并验证 AScript 后，再按 180–199 人提示关注、200 人及以上提示更换群二维码，未检测不会误报为安全。
