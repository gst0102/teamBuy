# Codex Handoff Prompt

请暂停继续开发，执行一次项目记忆更新。

请检查本轮对话、当前 Git 状态、当前 Git diff 和项目文件，然后更新以下文档：

## 1. `docs/dev-log.md`

记录：

- 本轮目标
- 本轮完成内容
- 修改了哪些文件
- 当前未完成事项
- 下一步建议

## 2. `docs/decisions.md`

只记录已经明确确认的产品或技术决策。

不要记录：

- 临时想法
- 未确认方案
- 猜测

## 3. `docs/pitfalls.md`

记录本轮遇到的坑、错误原因和避免方式。

重点记录：

- 平台限制
- 接口权限问题
- 数据污染风险
- 隐私和合规风险
- 容易被新 Codex 窗口重复犯的错误

## 4. `docs/handoff-latest.md`

生成给新 Codex 会话接手用的最新交接文档。

必须包含：

1. 项目背景与目标
2. 当前阶段目标
3. 已完成的功能
4. 已修改/新增的文件
5. 当前代码状态
6. 已知问题和风险
7. 用户已经确认过的产品/技术决策
8. 下一步建议执行顺序
9. 新 Codex 会话接手时的第一条提示词

## 要求

- 不要编造没有完成的内容。
- 不要把猜测写成事实。
- 文档要简洁但不要遗漏关键上下文。
- 每条记录带日期。
- 如果工作区有未提交改动，要明确列出。
- 不要批量删除文件。
