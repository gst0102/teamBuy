# 微信群工具三页面测试清单与验收标准

## 范围

本轮重构覆盖同一页面内的三个独立模式：`找群`、`我的发布`、`我的活码`。本轮只改本地代码和测试，不上传微信体验版、不部署生产。

## P0 / P1 验收项

- [ ] `找群`读取公开有效群资源；不读取或展示另一位用户的“我的发布”。
- [ ] `我的发布`只读取当前用户自己的资源；支持查看状态、删除和更新二维码。
- [ ] 找群只展示有效期内资源；城市、行业、用途筛选可组合使用。
- [ ] 发布时保存城市/行业/用途；同一用户每天最多新发布 1 个，奖励累计上限 100 分。
- [ ] 更新已有群二维码不重新计算发布奖励，并延长有效期。
- [ ] 查看二维码经服务端扣除统一互助积分；同一用户重复查看同一资源不重复扣分。
- [ ] 群资源二维码默认不在公开列表返回，扣分/本人查看后才返回二维码地址。
- [ ] `我的活码`直接上传二维码，系统自动命名，不要求填写名称。
- [ ] 活码更新二维码后固定入口 `publicUrl` 不变，外层活码二维码可下载到相册。
- [ ] 活码删除仅允许本人操作；群资源删除/更新仅允许本人操作。
- [ ] 活码上传必须成功解析完整 http/https 二维码链接；解析失败不能创建记录。

## 需要人工确认

- [ ] 微信开发者工具确认三个模式的视觉层级、按钮居中、筛选器和空态。
- [ ] 真机确认上传、下载到相册、权限弹窗、二维码展示和过期更新流程。
- [ ] 部署后确认 PostgreSQL 自动创建 `group_resources` 表和索引。
- [ ] 订阅消息“活码到期前提醒”本轮未接入此页面，仍需单独补充授权入口和定时发送验收。
- [ ] 发布奖励显示为“审核中”状态；后台审核/确认结算不是本轮新增的完整闭环。
