# 互助任务分享卡与过程记录 Codex 自测报告

日期：2026-09-02

## 范围

- 任务分享卡转化文案和固定 5:4 文字优先渲染。
- 小程序任务完成标准必填，普通任务完成标准统一命名。
- 发布者侧参与、提交、验收、结算统计和全量提交历史。
- 目标小程序打开、返回、取消、失败行为事件。

## 已实现

- 分享样式版本升级为 `mutual_task_share_v3`，原生分享路径仍指向具体任务详情；分享卡展示任务是什么、怎么完成、完成后获得什么。
- `share-snapshot` 归一化链路保留步骤、奖励和平台结算说明，避免生成图丢字段。
- 前端与服务端共同强制非羊毛任务存在有效完成标准。
- 服务端按任务聚合行为和提交状态；参与用户去重并排除任务发布者。管理详情显示执行者昵称及状态，不再隐藏已结算历史。
- 生产行为接口使用认证会话身份；新的行为事件必须对应已存在任务。
