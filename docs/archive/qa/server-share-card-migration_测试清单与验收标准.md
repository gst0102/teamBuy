# 后端分享卡片迁移：测试清单与验收标准

## P0 验收项

- [ ] 公开发布的普通资料可由后端生成并返回 `status=ready` 的分享图。
- [ ] 电子名片生成专属版式，头像为圆形区域，不把头像铺满整张卡片。
- [ ] 有真实图片的资料/任务生成包含该图片的分享图；无图片资料生成信息卡，不伪造默认图。
- [ ] 普通任务、小程序任务、羊毛福利分别能生成后端快照。
- [ ] 任务状态为暂停、结束、删除或剩余次数为 0 时不能生成可分享快照。
- [ ] 版本变化后旧快照不再被公开资料接口返回，重新准备后才得到新图。
- [ ] 生成失败、媒体读取失败或保存失败时旧当前图不被替换。
- [ ] 连续并发准备同一实体不会产生多个当前快照引用。
- [ ] 小程序资料和任务分享入口不再调用 Canvas 生成、`wx.canvasToTempFilePath` 或分享图上传接口。
- [ ] 最终 `onShareAppMessage` 在快照缺失、过期、生成失败、任务结束四种反例下均不会分享错误图片或错误页面。

## 关键验证

- 图片尺寸为 750×600，内容类型为 JPEG。
- 当前快照 URL 为本系统媒体地址，历史快照不覆盖当前引用。
- 任务卡片的 `sourceRevision`、`styleId`、`fingerprint` 与前端当前版本一致。
- 后端生成图读取的是服务端实体字段，客户端篡改展示文案不会改变最终生成内容。

## 未覆盖项

- 微信开发者工具和真机原生转发面板需要由用户在本地手动验证。
- 合集、商机市场、响应包分享卡本轮不迁移。
