# 上线闭环与真实分享追踪 V1 测试清单与验收标准

更新时间：2026-06-21

## 1. 验收结论规则

- P0 全部通过：可以进入人工真机确认。
- 任一 P0 不通过：不得上线。
- 小程序分享、打开和电话/复制微信必须真机补验；自动化测试只能覆盖后端和静态校验。

## 2. P0 测试项

| 编号 | 测试项 | 验收标准 |
| --- | --- | --- |
| P0-01 | 展示页分享路径携带追踪参数 | 从展示页列表分享时，路径包含 `showcaseId/sid/from/src`，并先落到 `pages/showcases/index` 中转 |
| P0-02 | 展示页预览分享也可追踪 | 预览态分享时生成 `shareId`，但预览本身不计浏览 |
| P0-03 | 客户打开记录 view | 客户打开已发布展示页后，后端产生 `view` 事件 |
| P0-04 | 客户点击资料记录 note_click | 点击展示页资料后，后端记录对应 `noteId` |
| P0-05 | 电话咨询记录 phone_click | 点击电话后计入咨询 |
| P0-06 | 复制微信记录 wechat_copy | 复制微信后计入咨询 |
| P0-07 | 事件归属 shareId | 同一次分享下的打开、点击资料、咨询使用同一个 `shareId` |
| P0-08 | 未发布页不可记录 | 草稿/下架展示页调用事件接口返回业务错误 |
| P0-09 | analytics owner 权限 | 只有展示页 owner 能查看效果数据 |
| P0-10 | 匿名访客不伪装实名 | 未登录客户只计入匿名访客，不显示成真实用户 |
| P0-11 | 经营看板聚合正确 | 打开、访客、看资料、咨询、分享批次计数与展示页事件一致 |
| P0-12 | 生产 mock 登录关闭 | 生产环境 `/api/auth/mock-login` 返回“测试登录已关闭” |

## 4. P2 暂缓项

- 渠道码和群来源。
- 趋势图和转化漏斗。
- 多设备匿名访客合并。
- 混合资料模板专项视觉回归。

## 5. 自动化测试建议

- 后端测试：
  - 创建、发布展示页。
  - 记录带 `shareId` 的 `share/view/note_click/phone_click/wechat_copy`。
  - 校验 analytics 统计和 topShares。
  - 校验经营看板 `summary.shareSourceCount` 和 `topShares`。
  - 校验非 owner 禁止查看 analytics。
  - 校验草稿页不能记录事件。
- 小程序静态测试：
  - 全量 JS `node --check`。
  - 全量 JSON 解析。
  - `git diff --check`。

## 6. 真机回归清单

1. 用户在展示页列表点击“发给客户”。
2. 用另一个微信或同微信另一设备打开分享页。
3. 打开后返回经营看板查看“打开/访客”是否增加。
4. 点击展示页内某条资料。
5. 返回展示页效果页查看“看资料”和资料点击排行。
6. 点击电话或复制微信。
7. 返回经营看板查看“咨询”是否增加。
8. 打开客户资料，确认手机号、微信、外呼、复制、跟进、备注可用。
9. 从展示页效果页点击最近访客，确认进入客户库后已按该客户搜索。
10. 从客户库当前筛选点击“看待联系 / 看订单”，确认来源或阶段筛选仍被带过去。

## 7. 上线前必须检查

- 清理生产测试数据。
- 确认生产 mock 登录关闭。
- 确认普通访客无法访问 owner 看板。
- 确认分享页只显示真实资料和真实联系方式。
- 确认匿名访客不会被当成实名客户展示。
