# 前四个 Tab 视觉收口_真机回归清单

更新时间：2026-06-28

适用范围：

- 首页
- 资料
- 合集
- 雷达

本清单用于本轮“四个 Tab 先收口风格、后细做内容”的真机验收。

当前验收原则：

- 首页需要同时保留 `雷达图 + 口号 banner`、`机会面板`、`把房源发给助手` 三块。
- 雷达页需要保留业务判断所需指标，不为了视觉压缩掉 `同行过滤` 等必要信息。
- 房源资料卡因业务特殊性，价格、地铁、面积、户型、朝向等标签允许更高信息密度。
- 非房源场景可以更轻、更克制，以减少大段说明文字和卡片噪音。

## 1. 回归前提

- 已上传最新体验版到微信开发者工具。
- 至少准备 3 类数据：
  - 有反馈数据的资料或合集
  - 无图片封面的资料或合集
  - 房源类资料
- 至少在一台普通手机和一台大屏手机上检查。

## 2. 全局收边项

### 2.1 视觉统一

通过标准：

- 前四个 Tab 顶部区域都属于同一套视觉语言：浅底、轻投影、圆角、浅描边成立，不再像四套独立页面。
- 标题、说明、胶囊、统计块、卡片边框粗细基本一致。
- 蓝白为主，但每页至少有一组辅助色用于区分重点，不再只剩单一蓝色层级。

### 2.2 文本密度

通过标准：

- 首屏同一区域内，不出现连续 3 行以上长度接近的说明文字。
- 次级说明明显比主标题轻，不抢主视觉。
- 能做成胶囊、短句、标签的信息，不继续写成长句。

### 2.3 居中与排版

通过标准：

- 按钮、状态标签、统计数字、右侧轻操作都上下左右居中。
- 不出现标签拆成两行、按钮文字偏上偏下、数字被挤压的情况。
- 页面在 iPhone 常规尺寸和大屏尺寸下都没有横向溢出。

### 2.4 无图兜底

通过标准：

- 资料卡和合集卡没有封面图时，不出现空白块、破图图标或比例塌陷。
- 无图卡仍然有可读的主视觉重点，至少标题、类型、核心引导能一眼分层。
- “打开小程序 / 输入同款”等推广引导仍然保留，不被无图兜底样式吃掉。

## 3. 首页

测试路径：

1. 打开首页。
2. 查看首屏 banner。
3. 查看“今日机会”面板。
4. 查看“把房源发给助手”区域。
5. 下滑查看最近反馈模块。

通过标准：

- banner 首屏一眼能同时看到：
  - 资料机会雷达定位
  - 核心口号
  - 雷达视觉主体
- banner 说明文字已收短，不再像说明书。
- `当前场景` 等胶囊信息轻量存在，不抢口号。
- “今日机会”统计块有层次，但不比 banner 更吵。
- “把房源发给助手”仍是强入口，并与上方模块留有清晰间距。
- 首页首屏不会因为信息过多显得堵，用户能在 3 秒内理解先看哪里、下一步做什么。

## 4. 资料页

测试路径：

1. 打开资料页。
2. 查看顶部说明区。
3. 查看房源类资料卡。
4. 查看普通资料卡或无图资料卡。
5. 查看卡片底部引导区。

通过标准：

- 顶部说明区比旧版更克制，不靠大段文案解释页面用途。
- 房源卡保留价格、地铁、面积、户型等核心标签，且信息仍能快速扫读。
- 非房源卡比房源卡更轻，信息层级更明确，不机械复用同一套重卡结构。
- 无图卡不会显得像“缺素材”，而是像一种刻意的轻设计卡。
- 卡片底部仍保留打开小程序、输入同款或类似传播引导，且字体更小、更像辅助提示，不压主信息。

## 5. 合集页

测试路径：

1. 打开合集页。
2. 查看顶部总说明和主入口。
3. 查看合集列表卡片。
4. 查看无图合集卡。
5. 查看右侧或底部操作区。

通过标准：

- 顶部区域能明确表达“这是把多条资料打包发出去”的感觉，不只是普通列表页。
- 合集卡的主标题、子说明、状态信息分层清楚。
- 无图合集卡仍有封面感，不能像纯文本列表。
- 卡片中的“打开小程序查看完整合集 / 输入同款”类传播引导仍然存在。
- 操作区紧凑，不会把左侧标题和摘要挤坏。

## 6. 雷达页

测试路径：

1. 打开雷达页。
2. 查看顶部 hero banner。
3. 查看分段切换区。
4. 查看优先跟进统计块。
5. 查看跟进队列和最近动作。

通过标准：

- 顶部 banner 已接近效果图方向：有雷达主体、浮动信号卡、短句口号和 AI 建议提示。
- 说明文案较旧版明显减少，重点落在“先看信号，再决定怎么跟”。
- `今日机会`、`AI 跟进建议`、模式胶囊等都是辅助信息，不压过雷达主体。
- `同行过滤`、`待跟进`、`访客`、`资料优化` 等业务分段仍完整保留。
- 统计块有辅助色区分，但整体仍属于同一页面体系，不像四张不同样式的卡硬拼。
- 空态文案不啰嗦，用户能明白下一步应该先发资料、再回来跟进。

## 7. 仍需人工判断的细节

- 首页 banner 的口号和副文案是否还可以再短一轮。
- 资料页无图卡是否要进一步做“标题重点词不超过 8 字”的轻封面方案。
- 合集卡的传播引导文案最终是否统一成一条固定句式。
- 雷达页辅助色是否还需要再拉开一点，增强 AI 感但不显花。

## 8. 当前建议执行顺序

1. 先上传体验版，按本清单做一轮真机截图对照。
2. 只记录阻断体验的问题：拥挤、错位、无图难看、重点不清。
3. 先修首页和雷达首屏，再修资料/合集卡片细节。
4. 四个 Tab 真机稳定后，再进入页内组件和业务内容深化。
