# 合集一级页重构：数据逻辑自测报告

日期：2026-08-13

## 范围

- 仅重构 `miniprogram/pages/showcases/index` 合集一级列表页。
- 新建合集、编辑合集、合集预览等二级页面保持原样。
- 未修改后端接口、数据库结构、生产或测试环境。

## 结果

- 合集页与资料页统一为“资料 / 合集”工作区切换。
- 有数据态提供搜索、最近、常发、高反馈、草稿和状态/类型筛选。
- 卡片按照发布状态提供明确主操作：已发布发客户、草稿继续编辑、已下架重新发布。
- 零数据态只解释合集用途并提供“新建第一个合集”和返回资料页入口。
- 移除一级页的产品宣传 Banner、生成同款、导出方案书和内嵌访客详情。

## 数据逻辑检查

- “最近”按 `updatedAt / createdAt` 排序，不隐藏旧合集。
- “常发”使用真实 `analytics.summary.shareCount >= 2`。
- “高反馈”使用真实打开、访客、资料点击或咨询聚合事件。
- 卡片只显示免费可见的汇总数据；真实访客和访问轨迹继续由雷达/效果页会员校验控制。
- 分享继续生成独立 `shareId` 并调用 `recordShowcaseEvent(eventType=share)`，没有绕过追踪链路。
- 分享成功后本地发送次数和卡片摘要立即更新。
- 合集一级页展示所有类型合集，房源、服务、商品、日常仅作为筛选，不再因当前工作模式隐藏其他合集。
- 发布、下架、删除和重新发布继续调用原接口；没有新增数据库字段。
- 接口加载失败与真实零数据分开显示。
