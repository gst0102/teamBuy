# 商机合作 V1 测试清单与验收标准

日期：2026-09-02

## 目标

验证“我的工具 → 商机合作”是否形成一条可用的合作发现闭环：用户可以制作并发布带有行业、细分行业、我能提供和当前合作意向的电子名片；其他用户可以在找合作/合作能力两个 Tab 中按需浏览，触底懒加载，进入公开详情，并在确认后用 1 个资源工具基础积分解锁联系方式。

## P0 验收项

### 1. 入口与建卡

- [ ] “我的工具”显示“商机合作”入口。
- [ ] 未登录用户点击后先进入登录；登录成功回到商机合作动作。
- [ ] 已登录但没有电子名片时，点击入口直接进入电子名片制作页。
- [ ] 已有名片时进入商机合作首页，不重复创建名片。

### 2. 名片字段

- [ ] 名片编辑页增加“商机合作标签”区域。
- [ ] 行业、细分行业、行业标签、我能提供、当前合作意向均可保存并回填。
- [ ] 行业使用细分选项，至少覆盖外贸、跨境电商、电商、企业服务、物流供应链、本地生活、房产、财税法律、设计营销、教育培训、健康美业和其他服务。
- [ ] “我能提供”至少填写 1 项，最多 6 项；未填写不能保存/发布。
- [ ] 当前合作意向为轻量可选字段，不要求用户另填独立合作发布表单。

### 3. 商机合作首页

- [ ] 页面包含“找合作 / 合作能力 / 我的名片”三个 Tab。
- [ ] 找合作只展示填写了当前合作意向且已发布、已开启商机展示的名片。
- [ ] 合作能力展示行业、城市、我能提供标签和一句话介绍。
- [ ] 支持关键词搜索、行业筛选和细分行业筛选。
- [ ] 首屏只请求一页卡片元数据，不等待详情或联系方式。
- [ ] 触底自动加载下一页，不重复请求、不重复卡片；无更多数据显示结束态。
- [ ] 卡片头像和非首屏图片使用懒加载，图片失败有首字母兜底。
- [ ] 无数据、加载失败和重试状态可感知。

### 4. 详情与积分

- [ ] 详情页可看到公开身份、行业、我能提供、合作意向和关于我。
- [ ] 未解锁时不返回、不展示电话、微信、邮箱、二维码等联系方式。
- [ ] 点击“查看完整联系方式”前明确提示消耗 1 个积分，并允许取消。
- [ ] 服务端只从资源工具积分钱包扣除 1 分；余额不足不扣分并返回明确错误。
- [ ] 同一用户对同一名片 24 小时内重复查看不重复扣分，联系方式仍可恢复。
- [ ] 不能查看自己名片时扣分。
- [ ] 名片下架/撤回后列表和详情不可见，解锁接口不能绕过发布状态。

## P1 验收项

- [ ] “我的名片”Tab 显示当前名片状态，并可进入编辑和客户页预览。
- [ ] 名片更新后商机列表不继续显示旧的行业、标签和合作意向。
- [ ] 资源工具积分余额与解锁后的余额一致。
- [ ] 接口失败不会用旧 mock 卡片冒充真实商机。
- [ ] 页面按钮、标签和筛选项使用 flex 居中、rpx、nowrap，真机不换行或偏移。

## 代码级检查

- `node --check` 覆盖新增/修改的小程序 JS。
- `python3 -m json.tool` 覆盖 app.json 和新增页面 JSON。
- `python3 -m compileall -q backend/app`。
- 定向 pytest 覆盖列表筛选、详情脱敏、1 分扣除、重复解锁、余额不足和自看名片。
- `git diff --check`。
