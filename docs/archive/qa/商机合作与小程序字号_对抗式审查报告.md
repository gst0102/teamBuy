# 商机合作发送语义与小程序字号对抗式审查报告

日期：2026-09-03

## 审查结论

当前代码没有把“发客户”做成保存后自动弹出微信分享面板：实际链路是“保存 → 发布 → 回到资料库 → 再点击微信原生分享”。这是微信原生分享的交互边界，不是保存失败，但按钮语义和用户预期存在 P1 级落差。

本轮不执行全局字号替换。全量静态扫描可以找出大量可能换行、溢出或变形的布局，但不能代替微信开发者工具的真实渲染；若把正文、按钮和标签统一改成同一套字号，会放大固定宽度控件的风险。

## 审查对象与成功标准

- 名片编辑页的保存、预览、发布和发客户动作。
- 全部小程序 WXSS 中的字号、固定宽度、`nowrap`、网格列和按钮操作区。
- 成功标准：保存结果不丢失；用户能理解下一步动作；字号变大后不造成关键文案裁切、按钮溢出、标签变形或布局错位。

## 高风险发现

### 1. “发客户”当前不是一次点击直发 —— P1 产品语义风险

`business-card-studio/index.js` 的 `handlePublish()` 会先调用 `handleSave()`，再调用 `publishNote()`，最后切换到 `/pages/library/index`。真正带 `open-type="share"` 的名片发送按钮位于资料库卡片中，用户还需要再次点击。

因此可以确认：当前已经满足“发客户前先保存”，但不满足“保存完成后立即弹出微信分享”。小程序没有可由异步 JavaScript 直接调用的原生分享面板；把编辑页按钮直接改为 `open-type="share"` 会让分享回调可能早于保存完成，反而可能发送旧 revision 或旧静态图。

最小正确语义是：

```text
保存并发布 → 进入资料库 → 点击发客户
```

如果产品必须做到真正的一次点击，需要先把名片保存和静态分享图准备做成前置状态，再由用户点击原生分享按钮；不能在同一个异步点击处理中伪造“保存后自动分享”。

### 2. 全局按钮默认 `nowrap`，字号放大存在系统性溢出风险 —— P1

`miniprogram/app.wxss` 的全局 `button` 规则设置了 `white-space: nowrap`。项目中还存在大量固定宽度、固定 flex basis 和固定网格列。全局把按钮字号统一提高到 30–32rpx 时，长文案不会自动换行，只能溢出、被截断或挤压相邻内容。

### 3. 名片编辑页已有两个直接高风险控件 —— P1

- `business-card-studio/index.wxss` 中 `.small-outline` 固定为 `64rpx` 宽，字号 `18rpx`。
- 同文件 `.qr-action` 也固定为 `64rpx` 宽，字号 `17rpx`。

如果直接改成 30rpx，两个“更换/添加”类按钮没有足够的安全余量；正确做法是先扩大操作区或把文字改为图标+短标签，再提高字号。

### 4. 商机详情页的联系人操作区不能跟随正文一起放大 —— P1

`business-opportunity-detail/index.wxss` 中联系人操作按钮固定为 `68rpx` 宽、字号 `17rpx`，整个操作区固定为 `144rpx`。拨打、复制这类短按钮可以单独维持小字号或扩大宽度，不能套用正文 28–30rpx。

### 5. 标签和状态胶囊属于“可变宽度”，但仍有溢出边界 —— P2

标签通常使用 `nowrap` 并依赖父级 `flex-wrap`，放大后主要表现为换行行数增加；但长行业标签、用户自定义服务关键词和状态文案可能单个超过屏幕宽度。需要同时设置最大宽度、溢出省略或允许标签内部断行，不能只改 `font-size`。

## 已确认较安全的范围

- 页面主标题、普通段落、输入内容：容器有 `min-width: 0` 或自然高度，适合按语义逐步提高到约 28–30rpx。
- 商机合作三列 Tab：当前主标题为 28rpx，四字以内的现有文案在三列布局中有余量；副标题仍需保留短文案和真机确认。
- 名片编辑页底部双按钮：等宽 grid 有足够水平空间，“保存并预览”在 30rpx 左右通常可容纳，但仍需检查小屏和系统字体差异。
- Canvas 分享图不受页面 WXSS 字号替换影响；分享图文字由 Canvas 绘制逻辑单独控制。

## 最小修正建议

1. 产品文案上明确“发客户”执行保存后发布，但不要承诺异步完成后自动弹出原生分享；如需消除歧义，可把中间状态提示写成“已保存并发布，去资料库点击发客户”。
2. 字号按语义分批调整：先正文、字段标题、输入内容和主要按钮，再处理标签/状态，最后处理角标和固定窄按钮。
3. 每次字号调整必须同步检查固定宽度操作区，优先处理 64–112rpx 的按钮和 `nowrap` 文案。
4. 真机验收至少覆盖普通 375 宽手机、小屏设备和大屏/iPad；检查编辑页、资料库、商机合作列表、商机详情、互助任务列表与详情。
