- 我的机会页包含页面标题、顶部雷达卡、匹配度数字、雷达图、最高匹配机会卡、匹配原因、建议动作、`生成回应包 / 查看联系方式 / 保存`。

- 详情页包含结构化摘要、行动建议、跟进状态，并突出 `生成回应包`。
- 已保存页按待联系、已联系、跟进中、无效分组，不做普通收藏列表。
- 订阅页使用标签点选配置我在找、我能提供、城市、联系方式要求、关键词和推送频率。
