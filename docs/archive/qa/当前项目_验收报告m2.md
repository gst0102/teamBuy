## 5. Bug 修复任务单

### BUG-SB-P2-001：展示页客户页跳转参数的验收文档与实现不一致

| 字段 | 内容 |
|---|---|
| Bug 标题 | 展示页 P0-08 验收标准中的跳转参数与实际小程序页面参数不一致 |
| 严重级别 | P2 |
| 所属模块 | 文档 / 小程序展示页 |
| 复现步骤 | 查看 `docs/qa/展示页构建器V1_测试清单与验收标准.md` 的 P0-08；再查看 `miniprogram/pages/showcase-view/index.js` 和 `miniprogram/pages/note-preview/index.js` |
| 实际结果 | 测试清单写进入 `pages/note-preview/index?noteId=xxx`；实现跳转为 `pages/note-preview/index?id=xxx`，目标页读取 `options.id` |
| 预期结果 | 验收标准与实际运行参数一致，或目标页同时兼容 `id` 和 `noteId` |
| 可能原因 | 文档编写时使用了语义化参数名，后续实现沿用项目已有 `id` 参数约定 |
| 建议修复方向 | 优先修正文档为 `pages/note-preview/index?id=xxx`；如需兼容外部链接，可让 `note-preview` 同时读取 `options.id || options.noteId` |
| 开发 Codex 执行指令 | 修正展示页 V1 测试清单 P0-08 的路径参数表述；可选增强 `note-preview` 参数兼容 |
| 修复后必须回归 | 真机点击展示页资料项，确认进入对应单条资料客户页 |
| 验收标准 | 文档、实现和真机行为一致，不再因参数名造成验收误判 |

本轮未发现 P0 / P1 阻断性代码 Bug。以上 P2 项不影响当前实现运行，但建议在最终验收前修正。

## 7. 上线前必须检查事项

- 在微信开发者工具中打开小程序，确认 `pages/showcases/index`、`pages/showcase-edit/index`、`pages/showcase-view/index` 均可正常进入。
- 使用真实或体验版登录态创建展示页，完成“选择资料 -> 保存草稿 -> 发布 -> 预览 / 客户打开”闭环。
- 用另一个用户或匿名客户视角访问已发布展示页，确认只能看到公开摘要，不能看到 owner 私有字段。
- 下架展示页后，客户公开链接必须不可访问。
- 修改一条已展示资料的标题、摘要和封面后，确认展示页读取最新资料摘要。
- 真机确认展示页资料卡点击后能进入正确的单条资料客户页。
- 真机确认电话拨号、微信号复制、banner 展示和分享卡片路径。
- 确认生产后端已部署 `/api/showcases` 相关接口，小程序体验版 `apiBaseUrl` 指向正确环境。
- 确认小程序上传、体验版发布和最终提交审核由用户在微信开发者工具中手动完成。
- 确认本轮未把密钥、Token、AppSecret 写入前端或 Git。

## 8. 最终建议

展示页构建器 V1 的后端和静态代码质量已达到进入人工验收的条件。建议下一步先执行小程序真机 / 微信开发者工具验收，重点覆盖 P0-07、P0-08；人工确认通过后，可将结论更新为“通过”。若人工验收发现运行时问题，再按 Bug 单进入开发修复和复测。
