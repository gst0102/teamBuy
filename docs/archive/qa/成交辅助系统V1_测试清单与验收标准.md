# 成交辅助系统 V1 测试清单与验收标准

更新时间：2026-06-27

## 1. P0 测试项

| 编号 | 模块 | 测试点 | 预期 |
| --- | --- | --- | --- |
| P0-01 | 权限 | 非 owner 请求 `/api/dashboard/business` | 返回 403 |
| P0-02 | 公开资料页 | viewer / 匿名访问公开资料 | 只返回公开字段，不返回私密字段、雷达、建议 |
| P0-03 | 公开合集页 | viewer / 匿名访问公开合集 | 只返回公开快照，不返回 owner 统计和客户列表 |
| P0-04 | 行为上报 | 公开资料页上报 `durationSeconds/focusSections` | 后端保存并进入 owner dashboard |
| P0-05 | 行为上报 | 公开合集页上报 `durationSeconds/focusSections` | 后端保存并进入 owner dashboard |
| P0-06 | 机会判断 | 咨询、预约、留资动作 | 标记为高意向 |
| P0-07 | 机会判断 | 停留超过 90 秒并看价格 / 联系方式 | 标记为高意向 |
| P0-08 | 机会判断 | 停留超过 30 秒但无咨询 | 标记为中意向 |
| P0-09 | 机会复活 | 沉默 3 天后再次打开 | 生成复活提醒 |
| P0-10 | 身份分层 | 同行 / 上游访问 | 不进入客户待跟进主池 |
| P0-11 | 首页 | owner 进入首页 | 显示“今日成交机会”和机会提醒 |
| P0-12 | 客户看板 | owner 进入反馈 / 客户看板 | 显示客户雷达、意向解释、跟进建议 |
| P0-13 | 客户页 | viewer 打开客户页 | 不显示“高意向 / 雷达 / 被分析”等后台文案 |

## 2. P1 测试项

| 编号 | 模块 | 测试点 | 预期 |
| --- | --- | --- | --- |

## 4. 人工真机验收

- 客户打开公开资料页后，客户页只看到公开内容。
- owner 回到首页能看到“今日成交机会”。
- owner 进入客户看板能看到客户雷达和建议话术。
- 同一资料 owner 自己预览不计入客户机会。
- 企业微信房源助手入口仍正常显示。
