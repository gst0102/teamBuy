# 房源中介对盘群增长 MVP 测试清单与验收标准

更新时间：2026-06-25

## 1. 验收结论规则

- P0 全部通过，且无阻断性 UI 问题，才能判定“通过”。
- 缺真机截图或体验版确认时，最多判定“需要人工确认”。
- 生成同款本轮是半自动引导，不得验收为完整后端克隆。

## 2. P0 测试项

| 编号 | 测试项 | 验收标准 |
|---|---|---|
| P0-01 | 默认房源版 | 首次进入首页默认房源工作台，不弹四工作台选择 |
| P0-02 | 隐藏其他工作台入口 | 首页不主动展示日常、团购、服务切换入口 |
| P0-03 | 不删除其他工作台代码 | app.json 页面、工作台配置和既有页面不被删除 |
| P0-04 | 房源合集页转化入口 | 房源合集公开页显示“我是中介，也想生成这种合集” |
| P0-05 | 房源卡页转化入口 | 单套房源公开页显示“生成同款房源卡” |
| P0-06 | 生成同款确认页 | 页面可填写微信号、上游联系人，并展示隐私边界 |
| P0-07 | 上游联系人默认值 | 从 A 发布者页面进入时，上游联系人默认 A，不显示 A 私密房东电话 |
| P0-08 | 微信号记忆 | 用户填过微信号后，再次进入自动带入 |
| P0-09 | 复制给助手 | 剪贴板内容包含来源、微信号、上游联系人和生成意图 |
| P0-10 | UI 基线 | 按钮文字居中、不溢出、不出现原生 button 撑开问题 |

## 3. P1 测试项

| 编号 | 测试项 | 验收标准 |
|---|---|---|
| P1-01 | 清单对比语境 | 房源合集清单页文案偏对盘效率，不混入商品/服务语境 |
| P1-02 | 精选橱窗语境 | 精选橱窗页仍保持客户可读，不被中介入口喧宾夺主 |
| P1-03 | 联系方式优先级 | 房源/合集页优先展示微信复制，电话为辅助 |
| P1-04 | 半自动说明 | 页面明确当前是复制给助手继续生成，不假装已完整克隆 |

## 5. 真机回归

- 微信里打开房源合集卡，页面底部中介入口不遮挡房源列表。
- 点击“我是中介”后，生成同款页按钮居中，输入框不被按钮挤出屏幕。
- 复制微信、复制给助手动作可用。
- 客户视角不出现房东电话被隐藏之类的敏感提示。
