## 3. 已覆盖检查

- 房源首页模式配置显示 `房源 / 打开 / 访客 / 待跟进`。
- 首页点击 `房源` 使用一次性本地筛选进入资料 Tab。
- 首页点击 `打开 / 访客 / 待跟进` 分别进入客户看板对应 Tab。
- 客户看板支持 `mode=property`，默认 `followup`。
- 客户看板保留 `推荐包效果`，用于承接多套房源一起发给客户的展示页能力。
- 资料页支持房源入口筛选和列表 / 双列展示。
- 工作台进入客户看板时携带当前 `workspaceMode`，避免非房源模式误进入房源客户看板。

## 5. 发现的问题

暂无阻断性代码问题。

本轮复核时发现开发初版可能让非房源模式默认进入房源客户看板，已补充修复：

- `pages/business-dashboard` 默认不再假设 `property`。
- `pages/home` 和 `pages/visits` 进入客户看板时携带当前模式。
- 非房源模式显示通用“分享效果 / 资料数据”文案，避免被房源语境污染。

## 6. 必须人工确认

- 房源首页四指标在真机是否居中、不截字。

- 资料页房源筛选和列表 / 双列切换在 iPad 上是否完整可读。
