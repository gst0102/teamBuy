# 服务方案销售页 V1 Codex 自测报告

日期：2026-06-22

## 结论

代码侧通过，真机 UI 和微信分享效果需要用户重新上传体验版后人工确认。

## 已覆盖

- 新增 `pages/service-offer-studio`，支持选风格、填方案、确认效果、保存并预览。
- “添加 -> 服务方案”进入独立工作台。
- 旧模板选择页选择服务方案时转入独立工作台。
- 已有 `service_offer` 可从笔记编辑页进入工作台切换方案样式。
- 服务方案字段拆成电话、微信、邮箱、网址。
- 客户页 `service_offer` 使用专属服务销售页结构，不展示商品 SKU、团购接龙或房源地图模块。
- 服务方案分享卡使用运行时 canvas 生成模板化封面，不新增本地图片资源。
- 服务方案保存时默认开启轻 SCRM、留资、预约和咨询，关闭团购接龙和支付预留。
