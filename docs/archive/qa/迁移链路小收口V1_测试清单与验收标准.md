# 迁移链路小收口 V1 测试清单与验收标准

日期：2026-06-22

## 范围

本轮不做新的“大型资料迁移工作台”，只在现有“我的笔记 / 资料库”里补迁移状态可见化。

## 验收项

### 1. 顶部迁移概览

- 进入“我的笔记”后，能看到“最近迁入”概览。
- 概览显示企业微信数量、手动/图片数量、图片待处理数量、候选确认数量。
- 有待处理资料时，右侧显示“X 条待处理 / 只看待处理”。
- 有待处理资料时，右侧显示“处理第一条”，点击进入下一条需要整理的资料详情。
- 没有待处理资料时，右侧显示“全部已入库 / 查看全部”，点击不会把列表筛空。

### 2. 单条资料来源和状态

- 普通笔记无房源/商品候选时显示“普通笔记”，不显示“待整理”。
- 有房源/商品候选的普通笔记显示“需要确认类型 / 确认整理”。
- 房源显示来源和“已整理成房源”。
- 商品/团购显示来源和“已整理成商品”。
- 图片资料显示“图片已保存 / 按需识别”，OCR 失败时显示“识别失败 / 重新识别”。

### 2.1 普通笔记详情

- 点击无业务候选的普通笔记，默认进入轻量笔记器，只展示标题、摘要、正文和保存/删除。
- 默认不展示功能组、标签专题、客户运营区块。
- 点击“扩展为可运营资料”后，才展开功能组、标签专题等运营能力。
- 点击“收起运营能力”后，回到轻量笔记器。

### 3. 一键确认类型

- 有房源候选的普通笔记显示“整理成房源”按钮。
- 有商品/团购候选的普通笔记显示“整理成商品”按钮。
- 点击按钮后弹出确认框，说明会保留原文和图片。
- 确认后调用后端 `confirm-type`，成功后进入对应 `note-edit` 工作台。
- 取消确认时不改变资料类型。
- 确认失败时提示错误，不改变列表状态。

### 4. 不改变原有主链路

- 点击资料仍进入现有 `note-edit`。
- 保存图片仍只保存图片，不自动 OCR。
- 房源/商品客户信息、分享和编辑入口不受影响。
- 原有分类、标签、专题、搜索仍可用。

## 验证命令

- 小程序相关 JS `node --check`。
- 小程序全量 JSON 解析。
- `git diff --check`。

## 人工真机检查

- 上传最新体验版后打开“我的笔记”。
- 看顶部“最近迁入”是否容易理解。
- 找一条房源、一条商品、一条普通笔记、一条图片资料，确认卡片上的来源和状态文字符合预期。
- 打开普通笔记，确认默认只是笔记编辑器，不出现复杂工作台。
- 点击“扩展为可运营资料”，确认可以展开功能组和标签专题。
- 点击“只看待处理”，确认只剩需要继续整理的资料。
- 点击“处理第一条”，确认能进入待处理资料详情。
- 找一条候选房源/商品资料，点击“整理成房源/商品”，确认进入对应详情工作台。
