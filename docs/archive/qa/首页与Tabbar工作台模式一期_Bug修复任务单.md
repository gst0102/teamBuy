## BUG-01：业务识别后缺少切换工作台专门提示

| 字段 | 内容 |
|---|---|
| 严重级别 | P0 |
| 所属模块 | 首页 / 模式切换 / 资料识别 |
| 对应测试项 | P0-23 |
| 复现步骤 | 1. 在日常资料台或其他工作台创建、导入或整理一条房源、商品或服务资料；2. 查看类型识别后的提示；3. 检查是否出现“切换到对应工作台”和“继续当前工作台”两个选择 |
| 实际结果 | 当前自测只说明“识别后不强迫转换资料类型”，尚未形成“是否切换到对应工作台”的专门提示链路 |
| 预期结果 | 系统可以建议用户切换到更合适的工作台，但必须提供继续当前工作台的选项；不能强制改变用户身份或资料归属 |
| 可能原因 | 类型识别提示只覆盖资料类型确认，没有串联 `workspaceMode` 切换建议 |
| 建议修复方向 | 在房源、商品、服务识别成功后的提示层增加两个明确动作：切换到对应工作台、继续当前工作台；切换只更新 `workspaceMode`，不改变资料归属 |
| 开发 Codex 执行指令 | 只补工作台切换提示，不重写类型识别主链路；房源建议切换 `property`，商品/团购建议切换 `groupbuy`，服务方案建议切换 `service`；用户选择继续时保持当前模式 |
| 修复后必须回归 | P0-03、P0-04、P0-07、P0-22、P0-23 |
| 验收标准 | 四种模式下都能触发对应提示；点击切换后首页和工作台同步变化；点击继续后资料保留在当前模式流程内；切换不删除资料、不改变 owner |

## BUG-02：权限和隐私未形成专项回归证据

| 字段 | 内容 |
|---|---|
| 严重级别 | P0 |
| 所属模块 | 工作台 / 经营看板 / 展示页效果 / 权限隔离 |
| 对应测试项 | P0-27 |
| 复现步骤 | 1. 使用 owner 账号创建资料、合集或展示页并产生看板数据；2. 使用非 owner 或普通访客访问相关页面；3. 尝试进入工作台、看板、客户数据、展示页效果数据 |
| 实际结果 | 自测报告仅说明本轮未做新后端权限变更，未提供专项接口、自动化或真机回归证据 |
| 预期结果 | 普通访客和非 owner 不能看到 owner 后台统计、客户数据、工作台数据；工作台迁移不破坏原有数据隔离 |
| 可能原因 | 本轮重点是前端信息架构迁移，权限回归未补证据 |
| 建议修复方向 | 补充权限回归脚本、测试或明确接口验证记录；如发现越权，再修复接口鉴权和前端入口拦截 |
| 开发 Codex 执行指令 | 至少覆盖 owner、非 owner、匿名访客三类身份；验证工作台总览、展示页效果、单条资料互动、客户看板数据不会越权返回 |
| 修复后必须回归 | P0-14、P0-15、P0-16、P0-25、P0-27 |
| 验收标准 | owner 可看自己的工作台和看板数据；非 owner / 匿名访客越权访问返回拒绝、空态或公开安全数据，不返回客户隐私和后台统计 |

## BUG-03：首页最近反馈未按反馈类型进入对应筛选

| 字段 | 内容 |
|---|---|
| 严重级别 | P1 |
| 所属模块 | 首页 / 工作台 / 最近反馈 |
| 对应测试项 | P1-10 |
| 复现步骤 | 1. 首页出现浏览、留资、咨询、接龙、预约等最近反馈；2. 点击某一类反馈；3. 查看进入页面是否自动筛选到对应类型 |
| 实际结果 | 自测报告显示入口可进入工作台，但未按具体反馈类型筛选 |
| 预期结果 | 点击不同反馈后进入工作台对应筛选或详情，减少用户二次查找 |
| 可能原因 | 首页反馈卡只做统一跳转，没有携带反馈类型参数 |
| 建议修复方向 | 为反馈入口补充 `type`、`tab`、`filter` 等轻量参数，工作台页面根据参数定位到对应筛选 |
| 开发 Codex 执行指令 | 保持现有工作台路由不大改，只补入口参数和目标页解析；无对应数据时显示该类型空态 |
| 修复后必须回归 | P0-14、P1-09、P1-10 |
| 验收标准 | 不同反馈入口能进入对应工作台分组；无数据时展示对应空态；普通模式仍使用“分享效果”语言 |

## BUG-04：资料页未按工作台模式做默认筛选或推荐

| 字段 | 内容 |
|---|---|
| 严重级别 | P1 |
| 所属模块 | 资料页 / 工作台模式 |
| 对应测试项 | P1-11 |
| 复现步骤 | 1. 切换到房源、团购或服务工作台；2. 打开“资料”Tab；3. 查看资料页默认筛选和推荐 |
| 实际结果 | 自测报告显示资料页暂未按 `workspaceMode` 做默认筛选，只做了资料库降噪 |
| 预期结果 | 当前模式下优先展示或推荐对应类型资料，同时保留查看全部资料的能力 |
| 可能原因 | `workspaceMode` 尚未接入资料页筛选默认值 |
| 建议修复方向 | 资料页读取当前工作台模式，设置默认筛选、推荐提示或快捷筛选；提供“全部资料”入口避免隐藏数据 |
| 开发 Codex 执行指令 | 轻量接入模式推荐，不要改资料归属和后端数据结构；日常模式默认全部或普通资料，房源模式优先房源，团购模式优先商品/团购，服务模式优先名片/服务方案 |
| 修复后必须回归 | P0-17、P0-18、P0-22、P1-11 |
| 验收标准 | 四种模式下资料页默认呈现符合当前模式；切换模式不删除、不改归属、不屏蔽全部资料 |

## BUG-05：合集页未按当前模式动态推荐

| 字段 | 内容 |
|---|---|
| 严重级别 | P1 |
| 所属模块 | 合集页 / 工作台模式 |
| 对应测试项 | P1-12 |
| 复现步骤 | 1. 分别切换日常、房源、团购、服务四种模式；2. 打开“合集”Tab；3. 查看空态和创建方向排序 |
| 实际结果 | 自测报告显示合集页固定展示四类方向，未按当前模式动态排序或突出推荐 |
| 预期结果 | 当前模式下突出最相关的合集方向，例如房源模式优先房源推荐合集，团购模式优先团购合集 |
| 可能原因 | 合集页一期轻版未接入模式推荐策略 |
| 建议修复方向 | 根据 `workspaceMode` 调整合集创建方向排序、标题或推荐标记 |
| 开发 Codex 执行指令 | 保持合集一期轻版，不开发完整专题合集；只做模式化推荐排序和文案强化 |
| 修复后必须回归 | P0-19、P0-20、P1-12 |
| 验收标准 | 四种模式下合集页可正常打开，推荐方向清晰，不影响其他类型合集入口 |

## BUG-06：`workspaceMode` 仅本地保存的边界说明不足

| 字段 | 内容 |
|---|---|
| 严重级别 | P1 |
| 所属模块 | 工作台模式 / 用户偏好 |
| 对应测试项 | P1-17 |
| 复现步骤 | 1. 设置任一 `workspaceMode`；2. 清缓存、换设备或重新登录；3. 查看是否保持原模式 |
| 实际结果 | 自测报告说明一期采用本地缓存，未做后端持久化；跨设备一致性不在本轮实现内 |
| 预期结果 | 如果本轮不做后端持久化，交付说明和自测报告必须明确；如果已有用户偏好接口可复用，可轻量持久化 |
| 可能原因 | 一期为信息架构重构，未纳入跨设备偏好同步 |
| 建议修复方向 | 不建议为此临时做大后端改造；优先在 Bug 修复报告中明确当前边界和后续建议 |
| 开发 Codex 执行指令 | 检查是否已有用户资料偏好接口可复用；若无，不新增大改造，只补交付说明和后续待办 |
| 修复后必须回归 | P0-04、P0-05、P0-21、P1-17 |
| 验收标准 | 当前版本边界清楚；用户清缓存后重新选择不会影响资料安全；后续持久化需求被明确记录 |

## 开发修复优先级

1. 先修 P0：BUG-01、BUG-02。
2. P0 修复后必须补 `docs/qa/首页与Tabbar工作台模式一期_Bug修复报告.md`。
3. P1 可尽量同轮修复；来不及必须在修复报告中明确未修原因和后续计划。
4. P0 未处理前，验收结论不得从“不通过”调整为“通过”。
5. 真机体验仍需用户上传最新体验版后人工确认。
