# 产品规划

## 1. 缺失信息与 v0.1 假设

阶段一信息已经足够生成 v0.1 开发文档，但以下信息仍需在阶段三接入前确认：

- 企业微信客服回调、`sync_msg`、媒体下载接口需要用真实企业微信账号调试。
- 微信笔记转发后的实际消息拆分方式需要实测。
- 小程序链接可解析字段范围需要实测。
- 大模型供应商、模型名称、调用成本和密钥管理方式待确认。
- 对象存储供应商、访问域名、私有/公开读策略待确认。
- 小程序 AppID、企业微信主体、客服账号、Token、EncodingAESKey、Secret 待提供。

v0.1 合理假设：

- 前端使用原生微信小程序，后端使用 FastAPI。
- 企业微信客服回调和消息拉取按真实接口设计。
- 无真实企业微信配置时，阶段三先用 mock 回调数据验证聚合和卡片生成。
- 对象存储先抽象为 `storage_service`，本地开发可 mock 为静态文件路径。
- 大模型先抽象为 `llm_parser`，无 API Key 时只跑规则解析。

## 2. 项目定位

teamBuy 是一个面向微信群私域场景的素材导入、卡片生成、分享查看、实名接龙与数据回看小程序。

一句话定位：一个通过企业微信客服导入微信笔记和链接，自动生成可复用素材卡片，并支持微信群查看、统计和实名接龙的小程序工具。

## 3. 目标用户

第一优先用户是房产中介。

核心场景包括：楼盘素材转发、活动信息发布、客户报名接龙、电话直拨、位置展示、浏览用户回看、历史素材复用。

第二优先用户是团购团长。

核心场景包括：商品素材导入、图文视频复用、微信群接龙、报名名单管理、浏览统计。

## 4. 核心场景

### 4.1 微信笔记导入

用户把微信笔记转发给企业微信客服。系统通过回调和 `sync_msg` 拉取消息，把同一用户、同一会话、60 秒窗口内的文本、图片、链接、位置、视频消息聚合成一次导入批次，并生成卡片草稿。

### 4.2 链接导入

用户把链接发给企业微信客服。系统按优先级尝试解析：

1. 小程序链接
2. 公众号链接
3. 普通网页链接

首版不承诺所有小程序链接都可完整解析。无法深度解析时，至少保存来源链接、标题候选、描述候选和缩略图候选。

### 4.3 卡片编辑与发布

发起人在小程序中认领导入记录，编辑卡片字段，保存后分享至微信群。

卡片字段为通用可选字段，不写死为房产或团购专用字段。

### 4.4 群内查看与接龙

群用户打开卡片后可以查看图文、视频、位置、电话、接龙说明，支持电话直拨和字段复制。接龙必须登录，不允许匿名。团长可以查看接龙名单、删除无效接龙、标记已跟进。

### 4.5 数据回看与复用

发起人可以在素材库查看卡片浏览人数、浏览次数、登录浏览用户、接龙人数和跟进状态，并可复制整张历史卡片重新发起。复用后新旧卡片数据独立统计。

### 4.6 客服侧边栏发卡片增强

当前 v0.1 主链路仍然是用户在小程序中认领、编辑、保存并分享卡片。

后续可技术预研企业微信客服侧边栏或工具栏 H5：客服在侧边栏中搜索已生成卡片，点击发送按钮后，通过企业微信提供的会话工具能力向客户发送小程序卡片。

该能力不纳入 v0.1 P0，原因是官方能力边界和接入条件需要实测确认，且会引入一个轻量 H5 工具页或 PC 侧边栏页面。

## 5. MVP 范围

### P0

- 企业微信客服回调接入
- `sync_msg` 消息拉取
- 微信笔记多消息聚合
- 文本、图片、链接、位置、视频基础解析
- 60 秒静默结束导入
- 企业微信客服回发导入成功或失败消息
- 待认领导入记录
- 小程序微信登录
- 首次导入后补绑定
- 卡片草稿生成
- 卡片编辑和保存
- 卡片分享至微信群
- 卡片查看页
- 电话点击直拨
- 字段复制
- 登录用户浏览记录
- 匿名浏览 PV/UV 统计
- 实名接龙
- 接龙名单查看
- 删除无效接龙
- 标记已跟进
- 素材库保存
- 一键复用整张历史卡片

### P1

- 素材库搜索
- 素材分类
- 每日浏览人数和浏览次数统计
- 浏览用户列表
- 接龙人数摘要
- 卡片字段展示开关
- 手机号、地址两个接龙附加字段配置
- 大模型兜底解析
- 链接优先级解析

### P2

- 高级智能分类
- 多行业模板
- 团队共享素材库
- 多客服分配
- 客服侧边栏/H5 发送小程序卡片能力预研
- 导出接龙名单
- 更复杂的表单字段
- 更完整的小程序链接深度解析
- 付费订阅和邀请返佣

## 6. 页面规划

| 页面 | 目标 | MVP 要求 |
|---|---|---|
| 登录页 | 建立用户身份 | 支持微信登录，登录后可进入素材库和认领页 |
| 待认领导入页 | 归属企业微信导入内容 | 展示待认领批次，支持确认归属 |
| 素材库页 | 管理卡片 | 展示卡片列表、搜索、分类、浏览摘要、接龙摘要、一键复用 |
| 卡片编辑页 | 编辑卡片字段 | 支持标题、封面、图文、视频、项目名、位置、电话、接龙说明、来源链接 |
| 卡片查看页 | 群用户查看内容 | 支持图文视频展示、电话拨号、字段复制、浏览统计、接龙入口 |
| 接龙提交页/弹层 | 实名接龙 | 默认头像昵称，可选手机号、地址 |
| 团长管理页 | 数据回看和名单管理 | 支持浏览数据、登录浏览用户、接龙名单、删除、标记跟进 |

## 7. 商业化与增长策略

v0.1 不实现商业化功能。

后续商业化建议围绕以下价值点设计：

- 导入次数
- 素材库存量
- 一键复用频率
- 活跃接龙数量
- 高级解析能力
- 团队素材库

原始商业化设想包括免费层、月费 9.9 元、年费 99 元、推荐返佣。该方案不进入 v0.1。
