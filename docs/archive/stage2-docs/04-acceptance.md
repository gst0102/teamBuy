# 验收标准

## 1. 总体验收目标

- [ ] 用户可以通过企业微信客服导入微信笔记或链接。
- [ ] 系统可以生成可编辑卡片草稿。
- [ ] 用户可以认领、编辑、保存、分享卡片。
- [ ] 群用户可以查看卡片、拨号、复制字段、实名接龙。
- [ ] 发起人可以查看浏览统计和接龙名单。
- [ ] 发起人可以一键复用整张历史卡片。
- [ ] P0 功能全部通过后，才允许进入人工上线确认。

## 2. 页面验收

- [ ] 登录页可以完成微信登录或 mock 登录。
- [ ] 待认领导入页展示当前用户可认领的导入记录。
- [ ] 素材库页展示卡片列表、搜索入口、分类入口、浏览摘要、接龙摘要。
- [ ] 卡片编辑页支持编辑标题、封面、图文详情、视频、项目名、位置、联系电话、接龙说明、来源链接。
- [ ] 卡片查看页可以展示已启用字段。
- [ ] 卡片查看页电话字段可以点击拨号。
- [ ] 卡片查看页关键字段可以复制。
- [ ] 接龙提交页或弹层可以提交实名接龙。
- [ ] 团长管理页可以查看浏览数据和接龙名单。

## 3. 功能验收

- [ ] 企业微信回调 GET 验证可通过。
- [ ] 企业微信回调 POST 事件可接收。
- [ ] `sync_msg` 或 mock 消息可以被拉取。
- [ ] 同一用户同一会话 60 秒窗口内消息可以聚合成一个导入批次。
- [ ] 微信笔记拆出的文本和图片可以生成卡片草稿。
- [ ] 链接消息可以生成来源链接和标题候选。
- [ ] 导入成功后企业微信客服回发成功消息。
- [ ] 导入失败后企业微信客服回发失败消息。
- [ ] 用户可以认领导入记录。
- [ ] 用户可以编辑并保存卡片。
- [ ] 用户可以分享卡片。
- [ ] 登录用户浏览卡片后出现在浏览用户列表。
- [ ] 匿名浏览只计入匿名 PV/UV，不出现在用户列表。
- [ ] 未登录用户不能提交接龙。
- [ ] 登录用户可以提交接龙。
- [ ] 手机号和地址字段由团长选择是否启用。
- [ ] 团长可以删除无效接龙。
- [ ] 团长可以标记已跟进。
- [ ] 一键复用会生成新卡片。
- [ ] 新卡片不继承旧卡片浏览和接龙数据。

## 4. 数据验收

- [ ] 原始消息被保存。
- [ ] 导入批次状态流转正确。
- [ ] 卡片状态流转正确。
- [ ] 媒体 URL 可访问或有明确缺失状态。
- [ ] 浏览 PV/UV 统计正确。
- [ ] 登录用户浏览记录与匿名浏览记录区分正确。
- [ ] 接龙记录和卡片关联正确。
- [ ] 删除接龙后不再显示为有效接龙。
- [ ] 标记跟进后状态可持久化。
- [ ] 复用卡片与原卡片数据隔离。

## 5. 性能验收

- [ ] 卡片查看页基本内容 2 秒内展示。
- [ ] 素材库列表支持分页或按需加载。
- [ ] 浏览记录写入不阻塞卡片查看。
- [ ] 导入解析失败不会导致服务崩溃。
- [ ] 大模型失败时仍能保留规则解析结果。

## 6. 安全与合规验收

- [ ] 前端代码不包含企业微信 Secret、Token、EncodingAESKey、AppSecret、大模型 Key。
- [ ] Git 仓库不包含真实密钥。
- [ ] 普通用户看到的接龙昵称已脱敏。
- [ ] 手机号和地址不向普通用户展示。
- [ ] 匿名用户不展示为实名浏览用户。
- [ ] 不包含收款、支付、订单、分账功能。

## 7. 代码质量验收

- [ ] 前后端目录结构清晰。
- [ ] 服务模块边界清晰。
- [ ] mock 数据可以替换为真实接口。
- [ ] 核心聚合和解析逻辑有测试覆盖。
- [ ] API 返回结构稳定。
- [ ] README 说明如何运行和测试。

## 8. 上线前检查

- [ ] 企业微信客服 API 管理模式已开启。
- [ ] 回调 URL 已配置。
- [ ] 小程序和企业微信主体符合官方要求。
- [ ] 对象存储可正常上传和访问。
- [ ] 线上环境变量配置完成。
- [ ] P0 测试全部通过。
- [ ] AI 测试官验收结论为通过或需要人工确认。
- [ ] 用户完成最终人工确认。
