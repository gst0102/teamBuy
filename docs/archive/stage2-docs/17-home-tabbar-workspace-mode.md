# 首页与 Tabbar 重构一期方案

更新时间：2026-06-23

## 1. 背景

当前资料整理助手已有多种资料能力：

- 普通笔记 / 日常资料。
- 电子名片。
- 房源。
- 团购商品。
- 服务方案 / 服务案例。

这些能力底层可以共用资料库、编辑、分享页、客户反馈和跟进能力，但前台如果全部平铺，会让用户误以为这是一个混杂工具：

- 普通用户不需要默认看到客户、线索、接龙和看板。
- 房产中介不需要默认看到团购。
- 团购团长不需要默认看到房源。
- 服务顾问不需要被普通笔记入口淹没。

因此一期重构重点不是新增业务功能，而是重构首页、Tabbar 和用户常用工作台模式，让用户进入后看到“这是我的工作台”。

## 2. 产品定位

对外定位：

```text
资料整理助手
把微信里的笔记、图片、链接和业务资料，整理成可编辑、可分享、可复用的资料库。
```

业务增强表达：

```text
对房源、团购、服务方案等业务资料，可以进一步生成客户页，记录浏览、咨询、留资、预约和跟进。
```

产品分层：

| 层级 | 说明 | 面向用户 |
|---|---|---|
| 基础层 | 资料归档、普通笔记、图片、链接、资料库、合集 | 所有用户 |
| 输出层 | 资料包、合集、分享页、模板、转发封面 | 所有用户 |
| 经营层 | 客户反馈、留资、预约、接龙、待联系、跟进看板 | 业务用户 |

SCRM 不作为前台主定位，只作为业务角色下的增强能力。

## 3. 一期目标

一期只解决导航和信息架构问题：

1. 建立统一 Tabbar 骨架。
2. 首页支持选择常用工作台模式。
3. 首页根据模式展示不同快捷入口和待处理事项。
4. 工作台页根据模式展示不同业务内容。
5. 资料库降噪，回归单条资料管理。
6. 合集页先占位为“资料包 / 合集”入口和空态，为后续专题合集中心铺路。

一期不要求完整实现专题合集中心的全部能力。

## 4. Tabbar 建议

统一使用 5 个底部 Tab：

```text
首页 / 资料 / 合集 / 工作台 / 我的
```

每个 Tab 的职责：

| Tab | 职责 | 不应该承担 |
|---|---|---|
| 首页 | 当前模式的今日工作台、快捷开始、最近反馈 | 不平铺所有功能 |
| 资料 | 单条资料管理、搜索、筛选、编辑、加入合集 | 不做经营看板主入口 |
| 合集 | 多条资料打包、资料包、分享合集入口 | 一期不做复杂 BI |
| 工作台 | 根据模式展示客户、接龙、模板或分享工具 | 不固定叫客户 |
| 我的 | 个人资料、会员权益、设置、帮助、邀请奖励 | 不放核心业务处理 |

第四个 Tab 前台可统一叫“工作台”，内容随用户模式变化，避免普通用户看到“客户”。

## 5. 常用工作台模式

内部建议使用 `workspaceMode` 表示当前常用工作台：

| 值 | 前台名称 | 适用用户 |
|---|---|---|
| `notes` | 日常资料台 / 资料整理台 | 普通资料整理用户 |
| `property` | 房源工作台 | 房产中介 |
| `groupbuy` | 团购工作台 | 团购团长 / 商品组织者 |
| `service` | 服务工作台 | 服务顾问 / 咨询 / 装修 / 美业 / 课程 |

注意：

- 这不是不可变身份，只是常用工作台偏好。
- 用户后续可以随时切换。
- 切换不删除资料，也不改变资料归属。
- 切换只影响首页、快捷入口、工作台内容、资料默认筛选、合集推荐和空态文案。

## 6. 首次进入首页

首次进入时，不建议问“你是什么行业”，而是问：

```text
你想先整理哪类资料？
```

首次选择页卡片：

### 日常资料台

说明：

```text
保存笔记、图片、链接，整理成资料包。
```

适合：

```text
备忘、文章、聊天资料、图片和日常记录。
```

### 房源工作台

说明：

```text
整理房源，生成客户推荐页，跟进看房客户。
```

适合：

```text
房产中介、租房买房推荐、看房客户。
```

### 团购工作台

说明：

```text
整理商品，生成团购页，管理接龙名单。
```

适合：

```text
团长、商品接龙、小区团购。
```

### 服务工作台

说明：

```text
制作名片和服务方案，记录咨询客户。
```

适合：

```text
咨询、装修、美业、课程、服务顾问。
```

### 兜底入口

```text
还不确定，先用日常资料台
```

用户选择后保存 `workspaceMode`，进入对应首页。

## 7. 二次进入首页

二次进入时直接进入对应工作台首页。

首页通用结构：

1. 顶部：当前工作台 + 切换入口。
2. 今日待处理：待审核导入、待编辑资料、待跟进事项。
3. 快捷开始：按模式展示 3-4 个主入口。
4. 最近成果：最近资料、最近合集、最近分享页。
5. 最近反馈：浏览、留资、咨询、接龙、预约等。

首页不平铺所有资料类型，也不展示当前模式无关功能。

## 8. 各模式首页内容

### 日常资料台

标题建议：

```text
资料整理台
```

今日待处理：

- 新导入资料。
- 待整理图片。
- 最近笔记。
- 未完成资料包。

快捷开始：

- 写笔记。
- 保存图片。
- 整理链接。
- 建资料包。

最近成果：

- 最近资料。
- 最近资料包。
- 最近分享。

不默认展示：

- 客户。
- 线索。
- 接龙。
- 看房。
- 预约。
- 买家。
- SCRM。

### 房源工作台

标题建议：

```text
房源工作台
```

今日待处理：

- 待审核房源。
- 待完善房源。
- 待跟进客户。
- 最近浏览房源。

快捷开始：

- 新建房源。
- 导入资料。
- 房源合集。
- 我的名片。

最近反馈：

- 谁看了房源。
- 谁留下电话。
- 谁预约看房。
- 哪个房源合集被打开。

### 团购工作台

标题建议：

```text
团购工作台
```

今日待处理：

- 待发布商品。
- 待处理接龙。
- 今日截止团购。
- 待联系买家。

快捷开始：

- 新建商品。
- 建团购合集。
- 查看接龙。
- 发群文案。

最近反馈：

- 谁参与接龙。
- 谁提交下单意向。
- 哪个商品被查看。

### 服务工作台

标题建议：

```text
服务工作台
```

今日待处理：

- 待完善服务方案。
- 新咨询客户。
- 最近被查看方案。
- 待跟进预约。

快捷开始：

- 做电子名片。
- 做服务方案。
- 建案例合集。
- 发给客户。

最近反馈：

- 谁看了名片。
- 谁看了服务方案。
- 谁留下联系方式。
- 谁预约沟通。

## 9. 工作台 Tab 内容

第四个 Tab 统一叫“工作台”，按模式切换内容：

| 模式 | 工作台内容 |
|---|---|
| 日常资料台 | 分享工具、模板、最近分享、资料包效果 |
| 房源工作台 | 看房客户、待跟进、预约看房、房源效果 |
| 团购工作台 | 接龙名单、买家记录、待处理订单/接龙 |
| 服务工作台 | 咨询客户、预约记录、服务方案效果 |

普通用户不看到“客户”Tab。业务用户在工作台里看到自己的客户/买家/接龙/咨询。

## 10. 客户看板归位

现有客户看板不要删除，它是业务资料的核心价值之一。但它不应该继续放在“我的”里，也不应该对所有用户默认露出。

客户看板应归位为：

```text
工作台里的反馈中心
```

### 数据来源

客户看板当前主要来自两类数据：

| 来源 | 记录什么 | 入口 |
|---|---|---|
| 展示页 / 合集 / 分享页 | 哪个页面被打开、哪次分享有效、哪个页面带来咨询或留资 | 工作台总览 + 展示页详情 |
| 单个资料 | 哪个房源、服务方案、商品或名片被看，谁咨询、留资、预约或接龙 | 工作台总览 + 资料详情 |

### 两级入口

第一层：工作台总览。

按模式展示整体反馈：

- 日常资料台：分享效果、最近分享、资料包浏览。
- 房源工作台：客户看板、房源效果、待跟进客户、预约看房。
- 团购工作台：接龙 / 买家看板、商品效果、接龙名单、待处理买家。
- 服务工作台：咨询看板、服务页效果、预约记录、咨询客户。

第二层：具体页面内入口。

在展示页、合集页、单条资料详情页里保留自己的效果入口：

```text
这个页面效果
浏览 28｜访客 12｜咨询 3｜留资 2
[查看详细效果]
```

```text
这条资料效果
浏览 8｜咨询 1｜留资 1
[查看客户互动]
```

### 前台命名

同一套底层数据，在不同模式下使用不同业务语言：

| 模式 | 前台名称 |
|---|---|
| 日常资料台 | 分享效果 |
| 房源工作台 | 客户看板 / 看房客户 |
| 团购工作台 | 接龙看板 / 买家记录 |
| 服务工作台 | 咨询看板 / 预约记录 |

普通用户不出现“客户看板”这个词。

### 与“我的”的边界

“我的”只放个人和系统相关内容：

- 个人资料。
- 会员权益。
- 设置。
- 帮助。
- 邀请奖励。

客户看板不是账号数据，而是工作反馈数据，应从“我的”迁到“工作台”。

## 11. 资料库降噪

资料库职责：

- 单条资料搜索。
- 单条资料筛选。
- 单条资料编辑。
- 单条资料分享。
- 单条资料加入合集。

资料卡核心动作：

- 编辑。
- 发给客户 / 分享。
- 加入合集。

资料库不再承担：

- 全部创建入口集合。
- 经营看板主入口。
- 客户跟进主入口。
- 模板中心主入口。

资料库可以保留“更多工具”入口，放置当前模式不常用但偶尔需要的功能。

## 12. 合集页一期设计

合集页一期先做轻版入口和空态，不急着做完整专题合集中心。

前台建议叫：

```text
合集
```

或：

```text
资料包
```

合集页定位：

```text
把多条资料打包成一个可分享、可复用、可转化的资料包。
```

一期推荐创建：

- 普通资料包。
- 房源推荐合集。
- 服务案例合集。
- 团购合集。

合集卡片信息：

- 合集标题。
- 一句话说明。
- 包含资料数。
- 资料类型构成。
- 最近更新。
- 分享状态。
- 简要数据：浏览、咨询、留资或接龙。

合集卡片动作：

- 查看。
- 发给客户 / 分享。
- 编辑。

一期空态文案示例：

```text
把相关资料放在一起，生成一个可以发给客户或朋友的资料包。
```

## 13. 模式切换

模式切换入口必须保留：

1. 首页顶部：

```text
当前：日常资料台  切换
```

2. 我的页设置：

```text
常用工作台
```

3. 业务识别提示：

当系统识别到房源、商品、服务资料时，提示：

```text
这条资料像房源信息。
是否切换到房源工作台，开启房源推荐页和看房客户跟进？

[继续用日常资料台] [切换到房源工作台]
```

模式切换必须轻，不要让用户以为这是不可逆身份选择。

## 14. 更多工具

不相关功能不要删除，先收进“更多工具”。

例如房源用户偶尔也要做服务方案，不应该完全屏蔽。

更多工具可包含：

- 普通笔记。
- 电子名片。
- 服务方案。
- 房源。
- 团购商品。
- 模板。
- 分享图。

首页只展示当前模式最相关的 3-4 个主入口。

## 15. 术语统一

前台尽量避免内部词。

| 内部词 | 前台建议 |
|---|---|
| UserNote | 资料 |
| Showcase | 分享页 / 资料包页面 |
| Topic | 合集 |
| SCRM | 客户跟进 |
| Lead | 待联系 |
| CustomerAction | 客户互动 / 互动记录 |
| workspaceMode | 常用工作台 |
| Dashboard | 看板 / 效果 / 反馈中心 |

## 16. 一期开发顺序建议

1. 重构 Tabbar：`首页 / 资料 / 合集 / 工作台 / 我的`。
2. 首页新增“选择常用工作台”首次引导。
3. 保存用户 `workspaceMode` 偏好。
4. 首页按 `workspaceMode` 展示不同模块。
5. 工作台 Tab 按 `workspaceMode` 展示不同内容。
6. 将现有客户看板从“我的”迁到工作台反馈中心。
7. 在展示页 / 合集 / 单条资料详情保留局部效果入口。
8. 资料库降噪，只保留资料管理、分享和加入合集。
9. 合集页先做轻版入口和空态。
10. 添加模式切换入口：首页顶部、我的页设置、业务识别提示。
11. 再进入专题合集中心的完整能力设计与开发。

## 17. 一期不做

- 不做完整专题合集中心。
- 不做复杂合集权限。
- 不做完整模板中心。
- 不做会员权益中心。
- 不做新增行业功能区。
- 不做完整 CRM。
- 不做正式商城、支付、库存、核销或分账。
- 不把所有资料类型继续平铺给所有用户。
- 不把客户看板继续作为“我的”里的账号数据展示。

## 18. 验收标准

### 信息架构

- 新用户首次进入能看到“你想先整理哪类资料？”。
- 用户可以选择日常资料台、房源工作台、团购工作台、服务工作台。
- 选择后首页内容随模式变化。
- 首页不再平铺所有功能。
- 普通用户默认不看到客户、线索、接龙、看房等业务入口。

### Tabbar

- Tabbar 为：首页、资料、合集、工作台、我的。
- 第四个 Tab 不固定叫客户，普通用户不会误解。
- 工作台内容随模式变化。
- 业务模式下可以从工作台进入客户 / 接龙 / 咨询看板。
- 日常资料台下只显示分享效果，不显示客户看板。

### 资料库

- 资料库聚焦单条资料管理。
- 单条资料有编辑、分享、加入合集入口。
- 资料库不再承担全部业务入口和经营看板入口。

### 客户看板

- 现有客户看板从“我的”迁出。
- 展示页整体效果在工作台总览和展示页详情都能进入。
- 单个资料客户互动在工作台总览和资料详情都能进入。
- 普通用户前台命名为“分享效果”，不出现客户、线索、SCRM 等业务词。
- 房源、团购、服务模式分别使用看房客户、接龙/买家、咨询客户等业务语言。

### 合集

- 合集页有清晰入口和空态。
- 用户能理解合集是“把多条资料打包成可分享资料包”。
- 一期至少展示普通资料包、房源推荐合集、服务案例合集、团购合集的创建方向。

### 切换

- 首页顶部可以切换常用工作台。
- 我的页设置可以修改常用工作台。
- 业务资料识别后可以提示切换到更合适的工作台。
- 切换不会删除资料或隐藏已保存资料。

## 19. 后续二期方向

一期完成后，再进入专题合集中心完整方案：

- 从资料卡加入合集。
- 合集内资料排序。
- 合集封面、标题、说明编辑。
- 生成可分享资料包页面。
- 房源合集生成客户推荐页 / 对比页。
- 服务合集生成案例资料包 / 服务辅助页。
- 团购合集生成团购合集页 / 接龙页。
- 合集分享效果数据。

一句话原则：

```text
先重构导航和模式，不要先堆新功能。
让用户一进来就知道“这是我的工作台”。
```
