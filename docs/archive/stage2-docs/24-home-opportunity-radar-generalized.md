# 首页 V2：资料机会雷达与四场景轻切换

## 背景

产品主线从“资料整理工具”升级为“销售助理”：

> 资料发出去，机会看得见。

资料整理仍是入口，但核心价值是：

- 看反馈。
- 找机会。
- 判断客户。
- 提醒下一步。

房源仍是当前主推尖刀场景，但首页不能只框死在房源，也不能把四个工作台做成功能超市。

## 产品原则

- 一个总心智：资料发出去，机会看得见。
- 四个使用场景：房源、商品、服务商机、资料。
- 房源默认推荐，但其他场景可轻量切换。
- 首页先展示“机会结果”，再展示“当前场景第一步”。
- 场景选择不是高频操作，不做大宫格常驻首页。

## 首页结构

### 1. 顶部 Banner

小标题：

- 资料机会雷达

主标题：

- 资料发出去，机会看得见

副标题：

- 谁看了、谁感兴趣、下一步怎么跟，这里帮你整理好。

右侧必须保留雷达图：

- 圆环雷达。
- 中心“客”。
- 客户标签：高意向 / 待跟进 / 复访。

顶部仅保留一个轻场景胶囊：

- 当前：房源场景
- 当前：商品场景
- 当前：服务商机场景
- 当前：日常资料场景

点击胶囊打开底部场景选择，不在首页常驻四宫格。

### 2. 今日机会

独立数据面板，不放在 banner 内。

四个指标：

- 高意向。
- 新打开。
- 待跟进。
- 待处理。

点击数字进入雷达或对应处理页。

机会提醒：

- 无数据时展示“还没有新的客户机会”。
- 有数据时展示最重要机会，并提供“复制话术”。

### 3. 当前场景第一步

根据当前场景切换，但同一位置只展示一个最重要第一动作：

- 房源：把房源发给助手 / 添加房源助手 / 整理房源合集。
- 商品：把商品发到群里 / 新建商品 / 商品合集。
- 服务商机：制作服务/商机页 / 做服务商机页 / 做个人名片。
- 资料：整理日常资料 / 写笔记 / 日常合集。

房源默认场景必须保留“把房源发给助手”，这是推广尖刀入口。

### 4. 最近有反馈的资料

按最近有客户行为、咨询动作、打开量排序，而不是按创建时间排序。

展示：

- 标题。
- 打开数。
- 互动/待处理数。

### 5. 弱场景入口

底部轻提示：

- 也可以用于商品、服务商机和资料包 · 切换场景

这是增长入口，不是首页主模块。

## 不做

- 不把四个工作台做成首页大宫格。
- 不删除房源助手入口。
- 不单独放大“客户雷达”卡片，因为今日机会数字和提醒都可进入雷达。
- 不自动切换用户常用场景，第一版只支持手动切换。

## 本轮实现

- 首页 banner 改为“资料机会雷达”总心智。
- 主标题改为“资料发出去，机会看得见”。
- 场景切换变成轻胶囊。
- 今日机会独立成数据面板。
- 移除首页单独客户雷达大卡。
- 当前场景第一步保留为独立操作卡。
- “最近成果”改为“最近有反馈的资料”。
- 底部新增轻场景切换入口。

## 验收标准

- 第一眼能记住“资料发出去，机会看得见”。
- 雷达图仍在第一屏，且视觉存在感足够强。
- 默认房源场景下，“把房源发给助手”仍清晰可见。
- 今日机会的数字和提醒可进入雷达或对应处理页。
- 首页不出现四场景大宫格。
- 场景切换不影响已保存资料，只影响首页和雷达展示。
- 手机和 iPad 上场景胶囊、机会指标、复制话术按钮不挤压、不错位。
