# 销售型 SCRM 五阶段开发规格

更新时间：2026-08-12

## 1. 产品结论

资料整理助手的核心循环固定为：

```text
免费制作资料 -> 免费生成卡片/合集 -> 分享 -> 产生客户信号
-> 19.9 元/月解锁客户信息链 -> 跟进 -> 生成同款继续传播
```

一句话定位：免费把销售资料做得更好、发得更远；付费看清谁感兴趣，并持续跟进客户。

## 2. 固定边界

- 创建、整理、生成、分享资料永久免费。
- 基础信号数量免费可见；具体身份、联系方式、完整轨迹、客户档案和跟进能力属于会员权益。
- 月度会员标价 19.9 元。
- 到期不删除资料或历史客户数据；只重新遮罩付费明细，续费后恢复。
- 首版推广奖励只计算本人直接邀请产生的有效会员订单，比例 50%。
- 不实现下下级 5% 自动现金分佣。
- 资源工具入口与内部结构全部冻结，不接入本轮会员墙和推广改造。
- 不部署生产；微信真实支付需后续配置商户参数并单独验收。

## 3. 阶段一：页面结构收口

### 首页

唯一任务：告诉销售今天发生了什么、下一步做什么。

- 首屏改为今日销售台。
- 动态主操作按“无资料 / 未分享 / 有信号 / 有待办”切换。
- 展示待跟进、新信号、待完善资料。
- 展示最高优先级客户信号、最近反馈资料、常用资料。
- 房源、商品、服务、商机、合集收进次级工具区。

### 资料页

唯一任务：快速找到适合发送的资料。

- 默认筛选收口为全部、最近、常发、高反馈、待完善。
- 类型筛选保留但降为次级。
- 房源、商品、标签、分类等复杂条件收进高级筛选。
- 卡片突出标题、关键字段、最近反馈、发客户和看信号。
- 合集仍可用，但定位为多条资料的发送方式。

### 雷达 / 客户

- 雷达：待处理、新信号、已完成。
- 客户详情：身份与联系、下一步、最近兴趣、跟进时间线、折叠档案。
- 高意向必须给出可解释原因，不能只有抽象分数。

### 我的

- 顶部展示用户与会员状态。
- 新增会员中心、推广收益、我的内容、设置帮助。
- 原资源工具整块保持现状，不改入口、不改文案、不改行为。

## 4. 阶段二：客户信息链

- 后端统一输出免费摘要和会员明细。
- 免费摘要：访客数量、重复查看数量、新互动数量、有反馈资料。
- 会员明细：可识别身份、联系方式、跨资料轨迹、兴趣解释、跟进历史和下一步。
- 匿名访客、登录访客、已留资客户必须分开表达。
- 客户时间线聚合浏览、资料点击、留资/预约/咨询、销售跟进。
- 所有 owner 数据接口继续校验 requester 与 owner 一致。

## 5. 阶段三：会员权益

### 数据模型

- `MembershipPlan`：月度方案、价格、权益清单。
- `MembershipOrder`：订单号、金额、状态、邀请归因、支付/退款时间。
- `MembershipEntitlement`：用户权益状态、有效期、来源订单。

### 状态

```text
pending -> paid -> refunded
                 -> expired（由有效期判断，不改历史订单）
```

- 同一支付流水必须幂等。
- 测试环境允许受控确认付款；生产必须由支付回调确认。
- 权益校验必须在后端完成，不能只靠前端遮罩。
- 免费用户访问会员明细返回可展示的锁定摘要，不泄露敏感字段。

## 6. 阶段四：生成同款

两种模式：

1. `reuse_content`：复用公开内容，替换为当前用户品牌和联系方式。
2. `use_own_content`：复用模板样式，使用当前用户选择的资料。

复制允许：公开标题、正文、结构字段、授权媒体、模板样式。

复制禁止：客户、统计、私密备注、上游联系人、订单、留资、跟进记录。

生成结果必须拥有新资料 ID、新分享路径和独立统计；保存来源模板、来源资料和邀请归因。

## 7. 阶段五：一级直接推广奖励

### 数据模型

- `ReferralRelation`：被邀请用户唯一绑定直接邀请人。
- `ReferralReward`：来源订单、奖励比例、金额、待结算/可提现/已提现/撤销状态。

### 规则

- 免费用户也可以分享邀请，不以付费作为推广资格。
- 只奖励直接邀请产生的真实付费订单。
- 每笔有效支付奖励 50%。
- 自购不奖励；同一用户只能绑定一个邀请人；绑定后不能自行改绑。
- 退款撤销对应奖励。
- 首版提现手续费为 0。
- 第一版提供账本和提现申请状态，不自动向个人账户打款。
- 不形成二级自动计酬关系。

## 8. 支付和奖励实现边界

- 本轮实现完整业务状态、持久化、权限、幂等、退款回退和测试确认适配器。
- 不在缺少微信支付商户配置时伪造真实付款。
- 真实微信支付、自动续费、企业付款到零钱和税务处理单独进入上线阶段。

## 9. 视觉方向

- 延续现有蓝白销售工作台，不重做品牌。
- 唯一视觉签名是首页“今日行动条”。
- 页面结构遵循：结论在前、主动作唯一、详情按需展开。
- 小程序尺寸继续使用 rpx，按钮与标签统一 flex 居中。

## 10. 五阶段完成条件

- 免费制作、生成和分享不被会员墙阻断。
- 免费用户可看到真实信号数量但无法获得付费明细。
- 会员可查看客户信息链并完成跟进。
- 会员到期后历史数据不丢失，续费后恢复。
- 生成同款不复制任何私密或统计数据。
- 直接邀请奖励按有效订单生成，退款可撤销。
- 资源工具没有发生结构或行为回归。
- 自动化验证通过后执行一次统一对抗式审查。
