# 发散想法：房产中介冷启动与同行裂变

更新时间：2026-06-23

## 1. 核心判断

资料整理助手后续冷启动，不建议一开始用“工具推广”的方式。

更适合的第一阶段切入口是：

```text
以真实中介身份发出一张好看的房源卡片，
让同行先看到结果，再被卡片里的钩子吸引进来。
```

也就是说，第一波不说：

```text
我做了一个资料整理助手，大家来试用。
```

而是先像正常中介一样发：

```text
芙蓉区 1600 内可看房源，整理了几套，想看的点开。
```

同行看到卡片效果，觉得“这个形式不错”，再通过卡片里的轻钩子进入生成流程。

## 2. 冷启动主路径

第一阶段路径：

```text
我以中介身份发房源卡片
  -> 同行在群里看到，觉得效果不错
  -> 点开卡片
  -> 卡片底部看到“我也想生成这样的房源卡片”
  -> 添加企业微信
  -> 企业微信自动发短视频教程
  -> 同行把房源资料发给企业微信
  -> 系统生成第一张房源卡片
  -> 同行转发给客户或群
  -> 后续看到浏览 / 留资 / 咨询反馈
```

这个路径比群里直接招募试用更自然。

核心不是先卖工具，而是先展示一个中介愿意转发的成品。

## 3. 第一张样板卡片必须像真实业务

第一张发出去的房源卡片要像真实中介会发给客户的内容，不要像产品广告。

标题示例：

- 芙蓉区 1600 元以内单身公寓推荐。
- 高桥北适合一个人住的 5 套房。
- 万家丽地铁口精装一房合集。
- 本周可看两房推荐。
- 张先生预算 1500-1800 房源推荐。

卡片重点：

- 标题像真实推荐。
- 图片清楚。
- 房源信息简洁。
- 电话 / 微信明确。
- 客户可以直接看懂。
- 同行看到后会好奇“这个怎么做的”。

## 4. 卡片内的传播钩子

每张房源卡片底部放一个低调入口，不能抢中介自己的客户转化。

入口文案示例：

```text
我也想生成这样的房源卡片
```

或：

```text
中介专用：把房源整理成客户推荐卡
```

或：

```text
3 分钟整理房源，发客户还能看反馈
```

点击后进入专门的引导页，不要进入普通首页。

引导页文案示例：

```text
你也可以生成这样的房源卡片

1. 添加企业微信
2. 把房源文案、图片或小程序卡片发过来
3. 自动生成可转发的小程序房源卡片
4. 可查看客户浏览、咨询和留资反馈

[添加企业微信，免费生成一张]
```

## 5. 企业微信承接

同行添加企业微信后，不要发长说明。

第一条消息建议：

```text
你把平时发客户的房源文案、图片或贝壳小程序卡片发给我，我会帮你整理成刚才那种房源卡片。
```

随后发一个 20-30 秒短视频教程。

视频内容只讲 6 步：

1. 把房源资料转发给企业微信。
2. 小程序里看到生成草稿。
3. 点一下确认 / 简单修改。
4. 生成房源卡片。
5. 转发给客户。
6. 查看谁浏览、谁留资、谁需要跟进。

第一阶段不要解释太多功能，不讲完整资料库，不讲复杂看板。

## 6. 首张卡片免费策略

第一阶段建议钩子是：

```text
免费生成第一张房源卡片
```

不要一开始讲“免费试用 7 天”，因为太抽象。

更自然的文案：

```text
第一次免费帮你生成 1 张房源卡片，满意再继续用。
```

中介最在意的是有没有一个能立刻发出去的东西。

## 7. 第二天反馈

同行发出第一张卡片后，第二天要主动给反馈。

反馈示例：

```text
你昨天发的房源卡片有 12 次打开，3 个客户重点看了第一套和第三套。

建议你今天先跟进这几个客户，可以这样说：
“昨天发你的几套房你看了没？我看你比较关注万家丽那套，要不要今天约个时间看？”
```

这里卖的不是页面，而是：

```text
知道谁该跟进。
```

这是后续收费的价值核心。

## 8. 第二阶段：邀请奖励

第一阶段先让同行觉得工具有用。

第二阶段再告诉他：

```text
你推荐同行开通，也能获得奖励。
```

不要在前台叫“分销中心”，建议叫：

```text
邀请奖励
```

文案方向：

```text
你觉得好用，推荐给同行，也能赚回会员费。
```

或：

```text
推荐同行使用资料整理助手，获得奖励。
```

奖励可以分层：

- 推荐同行注册并生成第一张卡：奖励次数 / 积分 / 会员时长。
- 推荐同行付费会员：奖励现金或会员时长。
- 推荐同行续费：继续给小比例奖励。

二级奖励可以有，但前台不要重点讲“二级”，避免显得像拉人头。

## 9. 最短冷启动动作

第一阶段可以这样执行：

1. 准备 3-5 张高质量房源样板卡片。
2. 以中介身份发到熟悉的中介群。
3. 不直接卖工具，只像真实房源推荐一样发。
4. 卡片底部放“我也要生成房源卡片”。
5. 同行点开后引导添加企业微信。
6. 企业微信发短视频教程。
7. 同行把资料发给企业微信。
8. 系统或人工辅助生成首张卡片。
9. 引导同行转发给客户。
10. 第二天给同行反馈浏览和跟进建议。
11. 再引导开通会员或邀请同行。

## 10. 前 20 个用户观察指标

第一波不要看注册数，主要看真实行为。

建议记录：

- 有多少同行点了“我也要生成房源卡片”。
- 有多少同行添加企业微信。
- 有多少同行发送真实房源资料。
- 生成了多少张房源卡片。
- 有多少同行把卡片转发给客户或群。
- 每张卡片平均打开次数。
- 是否产生咨询、留资、预约或微信复制。
- 是否有人愿意生成第二张。
- 是否有人愿意推荐同行。

如果前 20 个里有 5-8 个真实发出卡片，并且有人第二次使用，就说明路径成立。

## 11. 产品侧需要配合的关键体验

冷启动阶段不需要再加大功能，但以下体验要尽量顺：

1. 房源卡片第一眼要好看，像中介愿意发给客户的页面。
2. 卡片底部钩子要低调，不影响中介自己的客户转化。
3. 点击钩子后不能回普通首页，要进入中介生成房源卡片的专门引导页。
4. 加企业微信后流程要极短，最好一条消息 + 一个短视频就能说明。
5. 首张卡片生成要快，可以先人工辅助，不必第一天追求完全自动化。
6. 数据反馈要好懂：打开多少、哪套最多人看、谁留资、今天该跟进谁。
7. 跟进话术最好能一键复制。

## 12. 不要一开始推广的内容

第一阶段不要主推：

- AI 资料整理助手。
- 普通笔记。
- 全部功能。
- 企业微信会话归档能力。
- 复杂客户看板。
- 会员套餐。
- 二级分销。
- 团购 / 服务方案 / 电子名片全能力。

第一阶段只讲一个结果：

```text
把房源资料生成能发客户的小程序卡片。
```

## 13. 后续可沉淀成案例

理想案例表达：

```text
某中介用房源推荐卡发给 30 个客户，
8 人打开，
2 人留下联系方式，
1 人预约看房。
```

这样的案例比任何功能介绍都更有说服力。

## 14. 一句话总结

```text
先不要卖工具。
先用中介身份发出一个漂亮房源卡片，让同行看到结果。
同行好奇后，通过卡片钩子加企业微信，免费生成第一张。
等他发出去看到反馈，再进入会员和邀请奖励。
```
