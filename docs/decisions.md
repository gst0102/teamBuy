# Decisions

本文件只记录已经明确确认的产品或技术决策，不记录临时想法。

## 2026-06-08

### 决策：产品核心不是团购交易系统

选择：

teamBuy 首版定位为素材导入、卡片生成、查看统计、实名接龙与复用工具。

原因：

- 用户明确不做自己的资金收款功能。
- 当前更需要验证素材整理、复用、群传播和接龙统计价值。
- 不做交易系统可以降低支付、订单、履约、合规和服务器复杂度。

是否可调整：

后续可扩展商业化，但 v0.1 不做交易闭环。

## 2026-06-08

### 决策：第一批用户优先房产中介，其次团购团长

原因：

- 房产中介高频转发楼盘、活动、位置、电话、图文视频素材。
- 浏览用户、拨号、字段复制、接龙名单、跟进状态对房产中介价值明显。
- 团购团长作为第二批用户，可以复用通用卡片模型。

## 2026-06-08

### 决策：首版技术栈为原生微信小程序 + FastAPI

原因：

- 原生微信小程序更贴近微信群分享、微信登录、拨号、复制等能力。
- FastAPI 适合企业微信回调、消息聚合、媒体处理、大模型兜底和测试。

## 2026-06-08

### 决策：微信笔记必须支持，链接按优先级尽量支持

选择：

- 微信笔记为 P0。
- 链接支持优先级：小程序链接 > 公众号链接 > 普通网页链接。

原因：

- 微信笔记导入是项目差异点。
- 小程序链接深度解析存在平台边界，首版不承诺全量解析。

## 2026-06-08

### 决策：接龙必须登录，不允许匿名

原因：

- 接龙需要头像、昵称和后续跟进。
- 匿名接龙会降低名单真实性和管理价值。

补充：

- 手机号、地址作为团长可选附加字段。
- 普通用户看到接龙昵称必须脱敏。

## 2026-06-08

### 决策：浏览统计区分登录用户与匿名用户

选择：

- 登录用户进入浏览用户列表。
- 匿名用户只计入 PV/UV 总量，不展示身份。

原因：

- 未登录用户无法稳定获取头像昵称。
- 不能把匿名用户错误展示为实名浏览用户。

## 2026-06-08

### 决策：一键复用是复制整张历史卡片重新发起

原因：

- 复用后的新卡片需要独立统计浏览和接龙数据。
- 不允许复用覆盖原卡片历史数据。

## 2026-06-08

### 决策：客服侧边栏/H5 发小程序卡片不进入 v0.1 P0

原因：

- 官方能力边界需要实测确认。
- 会引入轻量 H5 或 PC 侧边栏页面，增加阶段三范围。
- v0.1 主链路仍以“小程序内编辑后分享卡片”为准。

后续：

- 作为 P2 技术预研。
- 参考企业微信文档 `92455` 和 `101463`。

## 2026-06-09

### 决策：悦享互动宝 v0.1 UI 只做产品化包装，不扩展真实业务

选择：

- 首页、资源库、发给客服、访问记录、我的页使用现有接口聚合展示。
- 会员、邀请、标签管理等没有真实接口的能力只做占位提示。
- tabBar 图标使用 `-a` 表示未选中，`-b` 表示选中；`tianjiakefu.png` 同时用于发给客服未选中和选中态。

原因：

- 当前重点是把已实现的 MVP 链路包装成可演示的小程序产品。
- 不引入支付、CRM、订单、AI 等超出 v0.1 范围的真实能力。
- 保持企业微信真实联调优先级，UI 改版不能阻断 `sync_msg` 权限问题排查。

## 2026-06-09

### 决策：企业微信真实导入受阻期间，先补齐手动添加资源入口

选择：

- 新增手动添加资源页和 `POST /api/cards` 创建草稿接口。
- 手动添加只生成草稿卡片，不绕过现有编辑、发布、查看、接龙和管理链路。
- 继续保留企业微信客服导入为核心主链路，手动添加作为本地验收和临时可用入口。

原因：

- 企业微信认证问题需要等待官方沟通，真实 `sync_msg` 暂时无法继续推进。
- 用户仍需要看到资料库、卡片发布和访问追踪功能可以完整运转。
- 手动添加可以复用现有后端卡片模型，不引入支付、订单、CRM 等额外范围。

## 2026-06-09

### 决策：v0.1 标签管理采用轻量分类标签，不做完整 CRM 标签系统

选择：

- 后端分类标签接口只支持列表、新增、删除。
- 卡片通过 `categoryIds` 绑定标签。
- 删除标签时从用户卡片中移除对应 `categoryId`。
- 资源库搜索和筛选优先使用自定义标签，未设置标签的卡片使用前端推断分类兜底。

原因：

- 当前目标是让资源库筛选和标签管理真实可用。
- 完整标签重命名、排序、批量打标、客户标签等属于后续增强，不进入本轮。

## 2026-06-09

### 决策：当前验收不能以本地 mock 通过替代上线通过

选择：

- 当前 AI 测试官验收结论为“不通过”。
- 后端自动化、mock 链路和小程序静态检查可以作为本地开发通过证据，但不能替代真实企业微信 `sync_msg`、真实媒体转存、真实微信登录和小程序真机/开发者工具验收。

原因：

- `sync_msg` 仍返回 `48002 api forbidden`，v0.1 主链路尚未真实跑通。
- P0 未全部覆盖时，项目规则明确不得给出“通过”。
- 小程序拨号、复制、分享、接龙等能力依赖微信运行环境，必须人工确认。
# 2026-06-09

### 决策：小程序页面统一改为 `navigationStyle: "custom"`

- `miniprogram/pages/*/index.json` 全部使用 `navigationStyle: "custom"`。
- 页面标题继续由页面内的 `brand-bar` / hero 区域承担，不依赖原生导航栏。

### 决策：手动添加资源页上传先走本地 `/media` 落盘

- 即使当前 `STORAGE_MODE=mock`，手动上传资源也优先返回真实 `/media/...` 地址。
