# PC 运营后台 V1 测试清单与验收标准

更新时间：2026-06-28

## 1. 验收原则

P0 未全部通过，不得判定为通过。

这一版重点验收：

- 后台访问控制
- 总览日报
- 用户排行
- 内容排行
- 群二维码批量上传
- 反馈工单
- 系统待处理

暂不验收：

- 资源积分真实后台化
- 用户积分人工修改生效到小程序
- 企业资源 / 群资源全量运营台

## 2. P0 测试项

### 2.1 后台访问

- 能访问 `PC 运营后台` 页面。
- 未提供管理员 Token 时，请求后台数据接口返回 403。
- 提供正确管理员 Token 后，后台页面可正常拉取数据。

### 2.2 总览页

- 能展示今日新增用户。
- 能展示今日新增资料。
- 能展示今日新增合集。
- 能展示今日客户动作。
- 能展示今日展示页打开。
- 能展示待发送通知和待处理异常。
- 趋势数据至少返回近 7 天。

### 2.3 用户排行

- 能返回用户列表。
- 用户列表至少包含昵称、注册时间、资料数、合集数、客户动作数、最近活跃时间。
- 支持关键字搜索用户昵称或 ID。
- 排序结果稳定，不出现明显空行或重复行。

### 2.4 内容排行

- 能展示合集排行。
- 能展示资料排行。
- 合集排行至少有打开数、点击数、咨询动作数。
- 资料排行至少有标题、所属用户、互动数、最近互动时间。

### 2.5 群二维码批量上传

- 支持粘贴多行文本后预览解析结果。
- 支持 `Tab`、`,`、`|` 三种分隔格式之一。
- 能区分成功行和失败行。
- 点击保存后能生成上传批次记录。
- 批次记录能展示导入条数、成功条数、失败条数、操作时间。

### 2.6 反馈工单

- 能创建工单。
- 能查看工单列表。
- 能按状态筛选工单。
- 能更新工单状态。
- 能填写回复内容。
- 能填写奖励积分备注。

### 2.7 系统待处理

- 能显示导入失败记录数量。
- 能显示待发送通知数量。
- 能显示媒体重试失败数量。
- 若存在同步失败任务，也能展示。

## 3. P1 测试项

- 总览支持空态。
- 用户排行支持无结果空态。
- 内容排行支持无结果空态。
- 反馈工单列表支持最近时间排序。
- 上传批次详情能查看失败原因。

## 4. 风险点

- 群资源积分、企业资源积分当前仍主要在前端本地，后台不能误展示为真实全局数据。
- 反馈工单若尚未接小程序前台提交通路，只能先验证后台录入和后台处理流程。
- 上传二维码批次当前是运营后台能力，不等于已经正式发布到前台资源库。
