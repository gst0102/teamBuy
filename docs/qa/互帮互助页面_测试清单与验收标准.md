# 互帮互助页面测试清单与验收标准

**阶段：页面交互实现**
**日期：2026-08-31**
**范围：小程序页面、普通分包、三种任务类型和图片内容块演示**

## 说明

本清单对应当前页面实现。后端尚未提供互帮互助任务、积分流水和媒体关联接口，因此当前页面使用本地演示适配器；真实积分结算、跨用户任务共享和线上图片资产登记不在本轮验收范围。

## P1 交互与视觉验收

- 页面使用 `rpx` 核心尺寸，按钮和标签文字上下左右居中，点击有按压反馈。
- 发布页只有一个主 CTA“确认发布”，表单字段有可见标签和辅助文案。
- 任务内容和验收标准区分清楚，不用标题猜任务类型。
- 小程序任务的反馈文字和图片可以为空；没有满足打开目标条件时不能提交完成。
- 普通任务详情的图片按内容顺序展示，提交页能删除已选图片。
- 页面底部保留安全空间，不让最后一个按钮被系统手势区遮挡。

## 后端接入后必须补测

- 任务跨用户读取、发布者积分排序和服务端分页稳定性。
- 图片上传登记 `MediaAsset`、哈希去重、权限校验和任务内容块关联。
- 发布时不预冻结积分；结算前余额不足时暂停任务，余额不能为负数。
- 小程序会话 nonce、有效停留、返回、幂等和重复结算校验。
- 普通任务领取、提交、补交、拒绝理由、超时验收、连续拒绝处罚和积分流水。
- 任务次数在并发验收下不能超额完成。

## 真机检查

- 微信开发者工具重新编译后检查主包和两个新增普通分包的大小与依赖。
- 375px 级别手机、较大屏手机和横屏分别检查顶部 Tab、表单滚动和底部安全区。
- 使用真实短链接和真实目标小程序验证打开、返回和完成链路。
- 使用真实账号验证登录回跳；本地演示数据不能作为生产积分数据。

## 羊毛后端接入后必须补测

- 解锁、打赏、退款和任务结算统一使用服务端积分流水、幂等键和原子事务；并发下不能重复扣分、重复退款或超出查看/完成名额。
- 羊毛查看名额按成功查看/解锁动作扣减，不能复用普通任务的提交次数或验收结算。
- 付费内容和评论可见性按任务状态、执行者解锁记录和分享 token 校验；不能仅信任前端 woolLocked。
- PC 端提供评论举报、退款申请、发布者违规处理和审计流水；处理结果要能回写小程序状态。
