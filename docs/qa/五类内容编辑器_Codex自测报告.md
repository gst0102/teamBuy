- 商品：新增独立 `product-editor`，覆盖商品、规格/履约、卖点、附件和供应商/成本私有字段。
- 服务 / 商机：`service-offer-studio` 改为轻量字段编辑器，支持图片、PDF、外链和合作条件。

## 2026-08-13 真机有数据态回归修正

用户用旧房源与合集数据在真机调试后，确认首次交付仍存在可见缺陷。本轮已追加修正：

- 资料、合集卡片和筛选弹层补齐窄屏收缩约束；固定栏和网格按钮统一 `width:100%`、`min-width:0`、`box-sizing:border-box`，避免右侧操作被推出屏幕。
- 房源、商品、服务编辑器改为“核心字段 + 更多公开信息 + 私密信息”渐进展开；旧数据已有值时自动展开，不丢内容。

- 通用文字/链接编辑器移除不符合规格的可拖动保存浮球；无封面的链接和客户页不再绘制巨大空白占位。
- 本人预览客户页时隐藏客户咨询动作和“生成同款”；旧文字标题、摘要和正文相同时去重。
- 资料/合集不再把异步分享图状态显示成“封面准备中”；可分享条目直接显示“发客户”，无来源资料显示“完善”。
- 新建资料识别卡移除重复的工作台切换按钮组，只保留保存与进入对应编辑器两项决策。
