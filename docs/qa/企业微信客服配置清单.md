# 企业微信客服配置清单

## 1. 你需要准备的配置

请在企业微信后台或部署环境中整理以下值，并填写到 `backend/.env`。

| 变量名 | 用途 | 从哪里获取 | 本地是否必须 |
|---|---|---|---|
| `PUBLIC_BASE_URL` | 企业微信回调公网域名，用来拼出回调 URL | 服务器公网域名或内网穿透地址 | 真实联调必须 |
| `WECOM_CORP_ID` | 企业微信企业 ID | 企业微信管理后台 | 真实联调必须 |
| `WECOM_CALLBACK_TOKEN` | 回调 Token | 微信客服 API 管理回调配置页自行设置 | 真实联调必须 |
| `WECOM_ENCODING_AES_KEY` | 回调消息加解密 Key | 微信客服 API 管理回调配置页生成或填写 | 真实联调必须 |
| `WECOM_SECRET` | 微信客服 Secret，用于获取 `access_token` | 微信客服 API 管理相关凭证 | 真实 `sync_msg` 必须 |
| `WECOM_OPEN_KFID` | 微信客服账号 ID | 微信客服账号配置或接口返回 | 真实 `sync_msg` 必须 |
| `WECOM_SYNC_CURSOR` | `sync_msg` 游标 | 首次可为空，后续保存接口返回 cursor | 可为空 |
| `WECOM_SYNC_LIMIT` | 每次拉取条数 | 本项目默认 100 | 可用默认 |
| `WECOM_USE_MOCK` | 是否使用 mock 导入 | 本地开发先 `true`，真实联调改 `false` | 必须 |

## 2. 推荐填写顺序

1. 先填写 `PUBLIC_BASE_URL`、`WECOM_CALLBACK_TOKEN`、`WECOM_ENCODING_AES_KEY`
2. 在企业微信客服后台把回调 URL 配成：`PUBLIC_BASE_URL/api/wecom/callback`
3. 再填写 `WECOM_CORP_ID`、`WECOM_SECRET`、`WECOM_OPEN_KFID`
4. 真实联调前把 `WECOM_USE_MOCK=false`
5. 启动后端后访问 `/api/wecom/config-check` 检查缺失项

## 3. 本地文件位置

- 本地真实配置文件：`backend/.env`
- 可提交模板文件：`backend/.env.example`

`backend/.env` 已被 `.gitignore` 忽略，不会进入 Git 提交。

## 4. 当前代码状态

- 已支持读取 `backend/.env`
- 已支持企业微信回调 GET 签名校验和 `echostr` 解密
- 已支持 POST XML 加密消息验签和解密入口
- 已提供真实 `sync_msg` 客户端骨架：`POST /api/wecom/real-sync`
- 本地开发仍保留 mock 导入：`POST /api/wecom/mock-sync`

## 5. 仍需真实账号实测的点

- 微信客服回调 XML 中具体事件字段
- `sync_msg` 返回的微信笔记、链接、图片、视频、位置消息结构
- media_id 下载接口和临时素材有效期
- 导入成功/失败客服消息回发接口
