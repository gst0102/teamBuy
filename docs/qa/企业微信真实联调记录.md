### 当前阻塞

真实 `sync_msg` 仍返回 `48002 api forbidden`。

手动触发：

```text
POST http://127.0.0.1:8002/api/wecom/real-sync?max_pages=1
```

企业微信返回：

```text
errcode=48002
errmsg=api forbidden
from ip=81.70.84.35
```

初步判断代码已成功请求到企业微信接口，当前更像企业微信后台权限问题。需要重点检查：

- `WECOM_SECRET` 是否为“微信客服”对应 Secret，不是小程序 Secret，也不是其他自建应用 Secret。
- 企业微信后台是否开启“微信客服-通过 API 管理微信客服帐号”。
- `WECOM_OPEN_KFID` 对应客服账号是否允许 API 管理。
- 企业微信后台是否需要配置可信 IP/白名单，加入 `81.70.84.35`。
- 当前企业/应用是否有微信客服相关 API 权限。
