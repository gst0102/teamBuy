# 合集收口：对抗式审查和复测报告

## 结论

实现已完成，自动化检查通过，进入用户统一人工验收；未部署生产。

## 已覆盖

- 场景到模板的服务端白名单与归一化。
- 房源、商品、服务、普通资料的合集编辑入口和同场景选择合集。
- 资料卡三个点：编辑、加入合集、复制、停止分享、重新发布、删除。
- 发布、下架、停止资料分享和公开快照边界。
- 旧 `sales-template-select` 路由引用静态扫描。

## 对抗式发现与修正

1. **高风险：撤回资料后公开合集快照仍可能保留旧内容。** 已新增关联快照失效并回归验证。
2. **高风险：仅前端限制模板会被直接请求绕过。** 已在创建、更新和公开快照服务端校验场景与资料类型。
3. **中风险：合集选择页卡片事件冒泡导致预览和选择同时触发。** 已改为 `catchtap`，选择模式从封面、主内容和卡片操作统一收口。
4. **中风险：历史房源批量标识被误当作新模板。** 已保留兼容 ID，渲染映射到房源精选模板。
