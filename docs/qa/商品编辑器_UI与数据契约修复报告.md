# 商品编辑器 UI 与数据契约修复报告

更新时间：2026-08-14

## 结论

商品编辑器已从旧通用结构化表单切换为商品专属页面，并按 `docs/png/editor-design/05-product-editor.png` 恢复核心信息层级。未部署生产、未上传小程序。

## 已修复

- 顶部改为客户实时预览，展示主图、商品名、最低价格、一句话卖点和当前销售方式。
- 商品图片前置，支持 1～9 张、预览、删除和长按设为封面。
- 销售方式使用单一 `inquiry | relay`；咨询模式不渲染接龙设置。
- 价格与规格使用简单行模型，金额保存为整数分 `priceFen`，每行提供有货/售罄。
- 商品亮点收口为最多 5 项，并保留选填商品说明。
- 配送、自提和地图选点渐进展开；PDF/链接只作为折叠补充资料。
- 接龙模式提供截止、限购、库存提示和履约说明。
- 供应商、成本、利润、内部库存、采购链接和内部备注进入 `privateData`。
- 底部改为“删除商品 / 保存并预览”。
- 客户预览兼容新 `variants/fulfillment/relayConfig`，并继续读取旧 `price/spec/skuConfig/pickupMethod/deadline`。
- 空白商品不再把“未命名商品、默认规格、商品说明”等提示文字写成真实数据；所有示例只使用输入控件 placeholder，历史系统占位值在编辑器加载时精确清空。
- `inquiry` 的编辑器界面名称统一为“商品”，底层枚举和客户“咨询购买”动作保持不变。
- 删除商品页中的房源文案和旧橙色状态横幅。
- 分享图片兜底覆盖资料库、旧笔记列表、资料详情页和旧编辑页；顺序为生成图、原封面、固定默认封面。旧笔记列表只预生成当前前 10 项。

## 自动验证

- `node --check`：商品编辑器、客户预览、旧编辑页、旧笔记列表、统一路由均通过。
- `app.json` JSON 解析通过。
- 涉及文件 `git diff --check` 通过。
- 反向文本检查通过：商品编辑器不再出现房源占位文案、旧横幅或旧底部按钮。
