# 客户数据看板测试清单与验收标准

更新时间：2026-06-21

## 1. 验收结论规则

- P0 全部通过，且无阻断问题，才可判定“通过”。
- P0 未覆盖或真机无法确认，判定“需要人工确认”。
- 出现数据串权、匿名当实名、假数据、入口不可用等问题，判定“不通过”。

## 2. P0 测试项

| 编号 | 测试项 | 验收标准 |
| --- | --- | --- |
| P0-01 | owner 打开访客线索页 | 可看到经营看板入口，不影响原有访客记录、笔记、线索、订单入口 |
| P0-02 | 经营看板数据来源 | 指标来自后端 `/api/dashboard/business`，没有前端写死假数据 |
| P0-03 | 展示页打开统计 | `ShowcaseEvent(view)` 能进入打开和访客统计 |
| P0-04 | 展示页资料点击统计 | `ShowcaseEvent(note_click)` 能进入看资料和资料点击排行 |
| P0-05 | 咨询统计 | 电话点击和复制微信进入咨询统计 |
| P0-06 | 匿名访客处理 | 匿名访客只计数或显示“匿名客户”，不展示为实名客户资料 |
| P0-07 | 客户线索入口 | 看板点击客户线索进入待联系页 |
| P0-08 | 订单/接龙入口 | 看板点击订单/接龙进入商家订单中心 |
| P0-09 | 展示页效果入口 | 看板点击展示页效果进入展示页列表 |
| P0-10 | 客户资料入口 | 看板点击客户资料进入客户库 |
| P0-11 | 商品动作不污染线索 | `order-intent / relay-intent` 不默认进入 `LeadReminder` |
| P0-12 | 权限边界 | 只统计当前 owner 的展示页、笔记、线索和订单数据 |
| P0-13 | 经营看板详情页 | 访客线索页的经营看板入口进入 `pages/business-dashboard/index`，详情页内四个 Tab 不直接替代旧处理页 |
| P0-14 | 四个看板 Tab | 详情页包含展示页效果、访客详情、笔记数据、客户资料四个 Tab |

## 3. P1 测试项

| 编号 | 测试项 | 验收标准 |
| --- | --- | --- |
| P1-01 | 最近访客列表 | 展示最近展示页访问，包含昵称/匿名、来源展示页、时间 |
| P1-02 | 资料点击排行 | 展示点击最多的资料标题和次数 |
| P1-03 | 最近客户动作 | 展示留资、预约、下单、接龙等事实动作 |
| P1-04 | 空数据状态 | 没有数据时页面不报错，展示 0 和空提示 |
| P1-05 | 小屏布局 | 经营看板卡片在真机窄屏不挤压变形 |

## 4. P2 暂缓项

- 跨展示页客户合并画像。
- 渠道码、来源渠道归因。
- 展示页到订单/线索的完整漏斗转化率。
- 成交金额和正式订单统计。

## 5. 回归清单

- 我的页原有资源统计、笔记入口、展示页入口、客户库入口、订单入口仍可用。
- 访客线索页经营看板入口进入经营看板详情页。
- 我的页只保留小入口，不展示整块经营看板。
- 经营看板详情页的“去处理”按钮再进入展示页、待联系、商家订单和客户库。
- 展示页列表现有效果展开不受影响。
- 单条笔记客户动作页仍可查看留资、预约、下单和接龙。
- 商品订单中心仍可按买家/商家角色查看。
- 客户库和待联系页仍只展示 owner 自己的客户资料。
