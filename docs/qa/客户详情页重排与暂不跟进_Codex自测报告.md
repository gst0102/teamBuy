## 已覆盖

- 客户详情页联系方式行使用可收缩左侧内容区和固定宽度右侧操作按钮。
- 手机号、微信号、邮箱显示为单行省略，复制仍使用完整原值。
- 中段不再重复显示“联系客户”，固定底部保留“记录跟进 / 联系客户”两个主动作。
- 固定底部增加“暂不跟进”，使用确认弹窗，文案明确保留资料和可恢复。
- 有 `leadId` 时直接更新已有跟进记录为 `paused`；无 `leadId` 时先调用现有客户跟进建档接口，再更新为 `paused`。
- 暂停、无效、完成状态在同一入口显示“恢复待跟进”，恢复时更新为 `pending`。
- 更新成功后清理客户雷达内存缓存，避免返回雷达继续显示旧的待跟进状态。
