# 客户跟进状态与客户详情 复测与回归报告

日期：2026-08-27

## 回归矩阵

| 场景 | 验证动作 | 结果 |
| --- | --- | --- |
| 连续点击 | 同一雷达卡片同时触发两次放弃 | 只发 1 次动作请求，客户从待跟进/访客移除并进入已放弃 |
| 超时 | 动作请求返回网络错误，详情对账也不可用 | 客户保持出队，不被旧数组重新加入 |
| 冷启动 | 清空进程缓存后打开客户详情 | 请求服务端并绘制客户身份、来源和线索状态 |
| 页面重进 | 再次打开同一客户详情 | 先立即显示内存快照，随后后台请求更新数据 |
| 旧响应 | 清理缓存后让旧请求晚于新请求返回 | 旧响应不能覆盖新快照 |
| 强制刷新 | 使用 `force` 触发后台重验证 | 不复用旧缓存，收到新响应后更新页面 |
| 版本冲突 | 使用过期 `expectedVersion` | 服务端拒绝覆盖并返回 409 |
| 跨客户参数 | A 客户身份配 B 客户线索 ID | 服务端返回 404，不执行状态变更 |
