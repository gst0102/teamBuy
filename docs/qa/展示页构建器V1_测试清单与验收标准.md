# 展示页构建器 V1 测试清单与验收标准

更新时间：2026-06-20

## 1. 验收结论规则

P0 未全部通过时，不得判定通过。

展示页构建器 V1 的验收结论只能是：

- 通过
- 不通过
- 需要人工确认

## 2. P0 测试项

### P0-01 创建展示页草稿

- 前置：用户已登录，且用户存在。
- 步骤：调用创建展示页接口，填写 name、description、contactConfig、items。
- 预期：返回 `draft` 展示页，ownerUserId 正确，items 被保存。

### P0-02 不能选择其他用户资料

- 前置：用户 A、用户 B 各有资料。
- 步骤：用户 A 创建展示页时传入用户 B 的 noteId。
- 预期：接口返回 400 或 403，不保存越权资料。

### P0-03 无有效资料不能发布

- 前置：展示页没有 items，或 items 全部 hidden / deleted / 无效。
- 步骤：调用发布接口。
- 预期：发布失败，返回明确错误。

### P0-04 发布后公开页可访问

- 前置：展示页有至少一条有效资料。
- 步骤：发布展示页，再调用公开接口。
- 预期：返回展示页信息和资料摘要，状态为 `published`。

### P0-05 未发布或已下架展示页不可公开访问

- 前置：展示页为 `draft` 或 `archived`。
- 步骤：调用公开接口。
- 预期：返回 404，不泄露草稿内容。

### P0-06 公开接口只返回可见资料摘要

- 前置：展示页包含可见资料、隐藏资料和被删除资料。
- 步骤：调用公开接口。
- 预期：只返回可见且 active 的资料摘要，不返回 owner 私有管理字段。

### P0-07 小程序构建页能保存并发布

- 前置：发布者小程序已登录。
- 步骤：进入展示页构建页，填写基础信息，勾选资料，保存并发布。
- 预期：页面提示成功，能进入客户展示页。

### P0-08 客户展示页能进入单条资料客户页

- 前置：展示页已发布且有资料。
- 步骤：客户打开展示页，点击资料。
- 预期：进入 `pages/note-preview/index?noteId=xxx`。

## 3. P1 测试项

### P1-01 展示页列表

- 步骤：发布者进入展示页列表。
- 预期：展示自己的展示页，不展示其他人的展示页。

### P1-02 编辑展示页

- 步骤：修改店名、简介、联系方式和选中资料后保存。
- 预期：再次打开详情时改动存在。

### P1-03 资料排序

- 步骤：在构建页上移 / 下移资料并保存。
- 预期：公开页按保存后的顺序展示。

### P1-03b 单条展示标题和分组

- 步骤：在构建页为已选资料填写展示标题和自定义分组标题。
- 预期：预览和公开页使用展示标题；选择自定义分组时按自定义分组展示。

### P1-04 下架展示页

- 步骤：发布后调用下架。
- 预期：owner 仍可编辑，公开接口不可访问。

### P1-05 资料更新后展示页读取最新摘要

- 步骤：发布展示页后修改其中一条资料标题或摘要。
- 预期：公开接口返回最新资料摘要。

### P1-06 联系方式展示

- 步骤：配置电话、微信号和联系文案。
- 预期：客户展示页按开关展示电话/微信，未配置时不展示空字段。

### P1-07 banner 上传

- 步骤：在构建页选择相册或拍照上传 banner。
- 预期：上传成功后回填 banner 地址，预览和公开页展示该 banner。

### P1-08 展示页真实效果追踪

- 步骤：客户打开已发布展示页，点击资料、电话咨询、复制微信、触发分享。
- 预期：发布者展示页列表可看到 PV/UV、资料点击、咨询点击、最近访客和资料点击排行。

### P1-09 效果看板权限

- 步骤：非展示页 owner 请求 `GET /api/showcases/{id}/analytics`。
- 预期：返回 403；匿名访客只统计数量，不展示成实名客户。

## 4. P2 测试项

### P2-01 分组展示

- 步骤：配置 groupBy 为 `cardType` 或自定义 sectionTitle。
- 预期：客户页能按基础分组展示资料。

### P2-02 分享标题

- 步骤：配置 shareTitle。
- 预期：小程序页面分享时使用展示页分享标题。

### P2-03 空态

- 步骤：用户没有资料时进入构建页。
- 预期：页面展示空态，可返回资料库添加资料。

### P2-04 四模板多尺寸视觉回归（暂缓）

- 步骤：在更多真机尺寸和系统字体设置下查看四个模板。
- 预期：无错位、重叠、挤压；该项等真实上线反馈后再开发专项适配。

### P2-05 商品/房源混合资料模板策略（暂缓）

- 步骤：同一展示页混入房源、商品、普通资料。
- 预期：模板文案和分组策略符合真实业务预期；该项等真实用户反馈后再设计。
