# 微信审核登录退出与头像选择自测报告

日期：2026-08-16

## 修改结论

1. 登录页增加“暂不登录，先浏览首页”按钮；有页面栈时同时显示导航返回。
2. 跳过登录固定进入公开首页，不回到触发登录的受保护录入页。
3. 个人资料头像使用直接可见的 `button open-type="chooseAvatar"`，头像和操作文案属于同一点击区域。
4. 头像点击、选择成功、未选择均有可见反馈；临时头像仍在保存资料时上传。

## 对抗式检查

- 拒绝协议后点击跳过：允许进入首页，不调用登录接口。
- 登录页作为首个页面：跳过按钮使用 `switchTab`，失败才 `reLaunch`，不会卡在登录页。
- 从资料录入触发登录：跳过后不会回到资料录入页，不会形成登录弹窗循环。
- 头像按钮：未设置 `disabled`，不是透明圆形占位，未嵌套在其他 button 内。
- 头像取消：空结果不会覆盖已有头像。
- 头像上传：只接受微信临时头像路径并在用户主动保存时上传；未改后端接口和生产配置。
