# 电子名片与服务方案模板库 V1 Codex 自测报告

日期：2026-06-22

## 范围

- 8 个销售页模板配置。
- 小程序模板选择页。
- 添加入口跳转到模板选择页。
- 使用模板创建资料并进入编辑页。
- 编辑页显示所选模板名。
- 客户页按模板信息渲染销售页结构。

## 已完成检查

- 电子名片模板：
  - 专业顾问。
  - 门店名片。
  - 专家介绍。
  - 简洁微信风。
- 服务方案模板：
  - 咨询预约。
  - 服务报价。
  - 案例背书。
  - 活动招募。
- 模板选择页：
  - 支持电子名片 / 服务方案切换。
  - 支持模板缩略预览。
  - 支持选中状态。
  - 支持底部确认使用模板。
- 创建链路：
  - 先调用原有手动资料草稿接口创建 `business_card` 或 `service_offer`。
  - 再调用原有资料更新接口写入模板默认字段和模板元信息。
  - 创建后进入原有编辑页继续修改。
- 客户页：
  - 电子名片突出头像、姓名、职位/公司、服务标签、联系方式和客户动作。
  - 服务方案突出服务标题、卖点、适合对象、流程、报价、案例和客户动作。
  - 两类客户页不展示商品 SKU、团购接龙或房源地图。
