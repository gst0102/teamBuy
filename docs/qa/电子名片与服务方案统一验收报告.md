- 电话咨询、微信咨询、留资、预约沟通、站内留言。
- `CustomerAction -> LeadReminder` 回流。

## 验收项

### 后端

- 已允许 `business_card` 和 `service_offer` 作为合法资料类型。
- 电子名片空白创建时可从用户资料带入昵称、头像和电话。
- 服务方案默认启用咨询、留资、预约沟通和轻 SCRM。
- 两类资料公开客户页接口可访问 active 资料。
- 留资和预约继续写入 `CustomerAction`，并投影到 `LeadReminder`。
- 服务方案不启用商品 SKU、下单、接龙、支付、库存或核销。

### 小程序资料库与创建入口

- “添加”页更多菜单包含电子名片和服务方案。
- 点击电子名片 / 服务方案后先进入模板选择页。
- 模板选择页包含 8 个销售页预览模板，支持电子名片 / 服务方案切换。
- 使用模板后创建对应资料卡，并进入编辑页继续修改。
- 资料库列表支持电子名片 / 服务方案标签、筛选和展示。

### 编辑页

- 电子名片字段覆盖头像、姓名、职位、公司/门店、服务范围、介绍、电话、微信、城市、二维码/图片。
- 服务方案字段覆盖服务名称、卖点、适合人群、服务内容、报价说明、流程、案例、服务地区、联系方式、预约说明、图片/视频。
- 编辑页顶部显示所选模板名。
- 两类资料继续复用电话咨询、微信咨询、留资、预约沟通、站内留言等转化功能配置。

### 客户页

- 电子名片客户页突出“人”：头像、姓名、职位/公司、服务标签、联系方式、服务介绍和客户动作。
- 服务方案客户页突出“服务价值”：标题、卖点、适合对象、服务内容、流程、报价说明、案例和客户动作。
- 客户页按模板 tone 和场景渲染销售页结构。
- 两类客户页不展示商品 SKU、团购接龙、商品下单、房源地图或预约看房专属模块。
- 客户页保留分享、电话咨询、复制微信、留资、预约沟通和站内留言能力。
