# 登录按需触发与未登录归档：Codex 自测报告

日期：2026-08-16

## 结论

本地代码整改完成。首页不再把登录作为首屏前置条件；需要创建或归属资料时才进入登录流程。企业微信会话存档与小程序登录保持解耦，未登录客户消息可以先生成待认领资料。

## 根因

`miniprogram/pages/home/index.js` 的 `onShow` 在没有 `currentUser` 时直接跳转 `/pages/login/index`，导致微信审核打开小程序即看到登录页。

## 改动

- 首页无用户时渲染匿名可浏览状态，不调用用户私有 dashboard、资料、订单、客户智能接口。
- 首页创建资料、图片/链接录入、房源/商品/服务/名片等需要账号归属的入口统一携带登录回跳地址。
- 资源创建页直达时仍有登录保护，登录后回到 `/pages/resource-create/index`。
- 首页清除私有状态，并校验异步请求对应的用户 ID，避免退出登录后旧数据回写。

## 会话存档验收判断

- 未登录客户向企业微信发送消息：可以由共享归档核心接收，teamBuy 入库后生成 `ownerUserId=unclaimed` 的资料。
- 未登录不等于匿名归属到某个用户：不会凭昵称、手机号或文本相似度自动绑定。
- 用户后续登录并完成明确绑定/认领：资料 owner、卡片、笔记和企业微信身份绑定才切换到该用户；后续消息可按绑定自动归属。
- 共享核心 24 小时 retention 只作用于核心中转原文，不影响已经写入 teamBuy 业务库的待认领资料。

## 本地验收标准

1. 清除 `currentUser` 后冷启动首页，不跳登录且页面可见。
2. 点击“添加资料/写笔记/新建商品/制作名片”等入口，才进入登录页。
3. 登录完成后回到原目标录入页，而不是无条件回首页。
4. 退出登录期间首页不显示之前账号的资料、客户信号或统计。
5. 未登录企业微信消息生成待认领资料，认领后归属正确用户。

## 未覆盖

- 微信开发者工具审核真机路径、真实企业微信实时回调和生产人工归档认领尚需负责人联调。
- 本轮未部署生产、未上传小程序体验版。
