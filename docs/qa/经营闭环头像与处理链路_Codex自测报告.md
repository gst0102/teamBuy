按以下顺序验收：

1. 上传最新体验版。
2. 先测头像兜底，确认没有白头像。
3. 再测经营看板从总数到具体访客。
4. 再测客户库、待联系、订单/接龙的具体人处理卡。
5. 最后测外呼、复制微信和另一个微信打开分享后的新记录。
