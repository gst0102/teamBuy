# 经营闭环头像与处理链路真机回归清单

日期：2026-06-22

## 回归前提

- 已上传最新小程序体验版。
- 测试微信号已加入体验成员。
- 后端为线上 `https://teambuy.lifelove.top`。
- 至少准备一条展示页分享、一条资料点击、一条留资/咨询、一条待联系线索、一条商品下单或接龙记录。

## 1. 头像兜底

测试路径：

- 我的页。
- 首页“谁看过我”。
- 访客线索。
- 经营看板访客列表和客户处理卡。
- 客户库客户列表和客户详情卡。
- 待联系线索列表和线索处理卡。
- 商家订单中心买家列表和订单处理卡。
- 展示页列表最近访客。
- 资料动作页下单/接龙名单。

通过标准：

- 没有真实 HTTPS 头像时，显示彩色文字头像。
- 不出现空白头像、白色方块、破图图标。
- 设置中心上传头像后，重新进入页面能看到真实头像或继续显示稳定兜底。

## 2. 经营看板

测试路径：

1. 进入“访客线索 -> 经营看板”。
2. 点击顶部“打开、访客、看资料、咨询”四个总数。
3. 点击“按展示页拆解”的某个展示页。
4. 点击“分享来源”的某个分享批次。
5. 点击“资料点击排行”的某条资料。
6. 在访客详情中点击具体客户行。

通过标准：

- 顶部四个总数能切到访客详情，并显示当前筛选。
- 展示页、分享来源、资料排行都能筛出对应访客。
- 客户行先弹出客户处理卡，不直接跳走。
- 处理卡能看到来源、看过资料、电话、微信和下一步处理入口。
- 外呼和复制微信可用。

## 3. 客户库

测试路径：

1. 进入客户库。
2. 点击阶段卡片：待处理、今日跟进、已联系、已归档。
3. 点击来源资料分组。
4. 点击客户头像/姓名区域。
5. 在客户详情卡点击“下一步处理、查看客户、来源资料”。

通过标准：

- 当前筛选文案会随点击变化。
- 列表只显示当前筛选下的具体客户。
- 客户详情卡展示阶段、意向、电话、微信、来源资料、最近查看、最近跟进、订单状态和标签。
- 下一步处理能按订单、电话、微信或客户详情正确执行。

## 4. 待联系

测试路径：

1. 进入待联系。
2. 点击今日、逾期、待处理客户。
3. 点击来源资料分组。
4. 点击线索头像/姓名区域。
5. 在线索详情卡点击“立即处理、查看线索、来源资料”。

通过标准：

- 当前筛选文案明确显示来源/状态/时间。
- 列表显示具体线索，而不是只有总数。
- 线索处理卡展示状态、跟进时间、电话、微信、来源资料、查看次数、备注和最近跟进。
- 立即处理优先拨号，其次复制微信；没有联系方式时进入线索详情。

## 5. 订单/接龙

测试路径：

1. 进入商家订单中心。
2. 点击订单状态：待处理、已联系、已完成、已取消。
3. 点击来源商品分组。
4. 点击具体订单卡。
5. 在买家订单处理卡点击“立即处理、查看订单”。

通过标准：

- 当前筛选文案明确显示来源商品或订单状态。
- 列表显示具体买家。
- 买家订单处理卡展示买家、状态、下单时间、来源商品、规格/数量、类型、备注、地址、电话和微信。
- 商家侧立即处理优先外呼，其次复制微信；无联系方式时进入订单详情。

## 6. 仍需人工确认

- 微信真机拨号权限和复制剪贴板提示。
- 小程序体验版是否确实为最新上传版本。
- 头像上传后的 HTTPS 域名是否在小程序合法域名内。
- 另一个微信打开分享后，是否能产生新的访客记录并进入经营看板。
