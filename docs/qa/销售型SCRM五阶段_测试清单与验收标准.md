# 销售型 SCRM 五阶段测试清单与验收标准

更新时间：2026-08-12

## 1. 验收总则

- P0 未全部通过不得判定完成。
- 页面能打开不等于通过；必须验证主动作、空态、会员边界和隐私边界。
- 资源工具作为冻结回归项，不允许被本轮会员或推广逻辑改变。

## 2. 阶段一：结构收口

### P0

- [ ] 首页五秒内可识别今日待办、新信号和唯一主操作。
- [ ] 无资料、无信号、有信号、有待办四种状态文案与动作正确。
- [ ] 资料页默认可快速搜索、筛选并发客户。
- [ ] 复杂筛选默认不占据主流程。
- [ ] 资料卡发客户动作不受会员状态影响。
- [ ] 雷达、客户、待办的页面职责和跳转不互相冲突。
- [ ] “我的”资源工具原入口、H5 ticket 和旧版回退逻辑保持不变。

### P1

- [ ] 主要按钮、胶囊、状态标签真机文字上下左右居中。
- [ ] 核心布局使用 rpx，长标题和窄屏不挤压主操作。
- [ ] 空态明确告诉用户下一步。

## 3. 阶段二：客户信息链

### P0

- [ ] 匿名访客不展示为实名客户。
- [x] 免费摘要只返回数量、模糊信号和资料级反馈，不泄露身份、电话、微信或完整轨迹。
- [ ] 会员明细正确聚合浏览、客户动作和销售跟进。
- [ ] 高意向信号带可解释原因。
- [x] owner/requester 不一致时拒绝访问。
- [ ] 客户时间线按时间倒序且不重复。

### P1

- [ ] 客户详情五秒内可看清最近兴趣、最近跟进和下一步。
- [ ] 拨号、复制微信、记录跟进等动作仍可用。

## 4. 阶段三：会员权益

### P0

- [x] 创建、编辑、生成、分享在免费状态可用。
- [x] 免费用户请求客户明细不会收到敏感字段。
- [x] 19.9 元订单金额以分为单位保存，避免浮点误差。
- [x] 同一支付流水重复确认不重复延长权益。
- [x] 已付款订单正确激活或顺延会员有效期。
- [ ] 到期后重新锁定明细但不删除数据。
- [ ] 续费后历史客户数据立即恢复。
- [x] 退款撤销对应订单权益；若存在后续有效订单，不错误关闭会员。
- [x] 生产环境不能调用测试付款确认接口。

### P1

- [ ] 我的页清楚显示会员状态、到期时间和19.9元月费。
- [ ] 付费墙从真实信号触发，能展示已发生的价值摘要。

## 5. 阶段四：生成同款

### P0

- [x] `reuse_content` 创建新 owner 的独立资料。
- [x] `use_own_content` 只复用模板，不覆盖用户原资料。
- [x] 联系方式替换为新用户资料。
- [x] 私密备注、上游联系方式、客户动作、统计、订单、跟进记录均不复制。
- [x] 新资料拥有独立统计和分享路径。
- [x] 无权限或已删除来源不能生成。
- [x] 同一幂等键重复提交不重复创建。

### P1

- [ ] 分享卡首屏可看见标题、主图、2–4 个核心字段。
- [ ] 客户转化按钮优先于“免费生成同款”。
- [ ] 三步内完成选择模式、确认信息、生成分享。

## 6. 阶段五：一级推广奖励

### P0

- [x] 免费用户也能生成邀请归因。
- [x] 被邀请用户只能绑定一个直接邀请人。
- [x] 自购和循环邀请不建立关系。
- [x] 每笔有效19.9元订单只生成一次50%奖励，即995分。
- [x] 续费订单继续为同一直接邀请人生成奖励。
- [x] 不生成二级5%自动奖励。
- [x] 退款后对应奖励撤销。
- [x] 待结算、可提现、已提现、撤销金额统计正确。
- [x] 不允许提现超过可提现金额。
- [x] 奖励账本不能被普通用户修改。

### P1

- [ ] 我的页能查看邀请数、有效付费用户数和奖励状态。
- [ ] 前台不使用团队层级、下线等高风险表达。

## 7. 跨阶段回归

- [x] 微信登录与 mock 登录原有测试通过。
- [x] 企业微信导入、资料列表、资料编辑、分享查看不回归。
- [x] 客户动作、线索、合集、订单和消息接口不回归。
- [ ] 资源工具入口和 H5 ticket 流程不回归。
- [x] JSON repository 与 PostgreSQL schema 均包含新增模型。
- [x] `.env`、Secret、Token 和私钥未进入 Git diff。

> 未勾选项需要微信开发者工具或真机人工验收，不能用静态检查替代。

## 8. 统一对抗式审查范围

- 权限绕过与前端假锁。
- 匿名身份误关联。
- 订单重复确认、退款和权益时间计算。
- 奖励重复生成、自购、循环邀请和退款套利。
- 生成同款的隐私泄露、媒体权利和统计串线。
- 页面主流程是否因功能过多再次变复杂。
- 资源工具是否被意外改动。
