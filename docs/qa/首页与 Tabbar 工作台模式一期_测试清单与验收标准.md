# 首页与 Tabbar 工作台模式一期_测试清单与验收标准

更新时间：2026-06-23

参考开发文档：

- `docs/stage2-docs/17-home-tabbar-workspace-mode.md`

## 1. 验收结论规则

验收结论只能是：

- `通过`
- `不通过`
- `需要人工确认`

判定规则：

- P0 全部通过，且真机主链路无阻断：可以进入人工上线确认。
- 任一 P0 不通过：不得上线。
- 小程序 Tabbar、首次引导、模式切换、首页布局和工作台入口必须真机确认；自动化测试只能覆盖路由、配置、状态保存和基础静态检查。
- 一期只验收导航和信息架构重构，不把完整专题合集中心、完整 CRM、支付、库存、商城或会员权益中心纳入通过条件。

## 2. 测试范围

本轮验收覆盖：

- 统一 Tabbar：`首页 / 资料 / 合集 / 工作台 / 我的`。
- 首次进入首页的常用工作台模式选择。
- `workspaceMode` 偏好保存、二次进入恢复、随时切换。
- 首页按模式展示今日待处理、快捷开始、最近成果、最近反馈。
- 工作台 Tab 按模式展示不同业务内容和前台命名。
- 客户看板从“我的”迁出，归位到工作台反馈中心。
- 资料库降噪，回归单条资料管理。
- 合集页一期轻版入口和空态。
- 首页顶部、我的页设置、业务识别提示的模式切换入口。
- 普通用户不默认看到客户、线索、接龙、看房、SCRM 等业务入口。

本轮不覆盖：

- 完整专题合集中心。
- 复杂合集权限。
- 完整模板中心。
- 会员权益中心。
- 新增行业功能区。
- 完整 CRM。
- 正式商城、支付、库存、核销或分账。

## 3. P0 测试项

| 编号 | 测试项 | 前置条件 | 操作步骤 | 验收标准 |
| --- | --- | --- | --- | --- |
| P0-01 | Tabbar 五项固定 | 小程序启动成功 | 打开小程序，查看底部 Tabbar | Tabbar 只显示 `首页 / 资料 / 合集 / 工作台 / 我的`；不存在旧的“客户”Tab 或混乱命名 |
| P0-02 | 第四个 Tab 统一叫工作台 | 小程序启动成功 | 查看底部第 4 个 Tab | 前台名称为“工作台”；普通用户不会看到固定“客户”Tab |
| P0-03 | 首次进入展示模式选择 | 新用户或清空 `workspaceMode` | 首次进入首页 | 展示“你想先整理哪类资料？”选择页；可选日常资料台、房源工作台、团购工作台、服务工作台，以及“还不确定，先用日常资料台” |
| P0-04 | 首次选择能保存模式 | 首次进入模式选择页 | 选择任一工作台模式 | 系统保存 `workspaceMode`，进入对应首页；刷新或重新进入仍保持该模式 |
| P0-05 | 二次进入不重复打扰 | 已保存 `workspaceMode` | 关闭并重新打开小程序首页 | 直接进入对应工作台首页，不再强制弹出首次选择页 |
| P0-06 | 首页顶部显示当前模式和切换入口 | 已保存任一模式 | 打开首页 | 顶部显示当前工作台名称，并有清晰“切换”入口 |
| P0-07 | 首页内容随模式变化 | 分别切换 4 种模式 | 逐个查看首页 | 首页标题、今日待处理、快捷开始、最近成果/反馈按模式变化，不平铺所有功能 |
| P0-08 | 日常资料台不暴露经营词 | `workspaceMode=notes` | 打开首页和工作台 | 不默认展示客户、线索、接龙、看房、预约、买家、SCRM；可看到写笔记、保存图片、整理链接、建资料包等资料整理入口 |
| P0-09 | 房源工作台展示房源语义 | `workspaceMode=property` | 打开首页和工作台 | 首页/工作台使用房源、看房客户、预约看房、房源效果等语义；快捷入口包含新建房源、导入资料、房源合集、我的名片 |
| P0-10 | 团购工作台展示团购语义 | `workspaceMode=groupbuy` | 打开首页和工作台 | 首页/工作台使用团购、接龙、买家、待处理订单/接龙等语义；快捷入口包含新建商品、建团购合集、查看接龙、发群文案 |
| P0-11 | 服务工作台展示服务语义 | `workspaceMode=service` | 打开首页和工作台 | 首页/工作台使用服务方案、咨询客户、预约记录、服务方案效果等语义；快捷入口包含做电子名片、做服务方案、建案例合集、发给客户 |
| P0-12 | 工作台 Tab 内容按模式变化 | 已保存不同模式 | 点击底部“工作台” | 日常资料台显示分享工具/模板/最近分享/资料包效果；房源显示看房客户/待跟进/预约/房源效果；团购显示接龙名单/买家记录/待处理订单；服务显示咨询客户/预约记录/服务方案效果 |
| P0-13 | 客户看板从“我的”迁出 | 已登录用户 | 打开“我的”页 | “我的”只放个人资料、会员权益、设置、帮助、邀请奖励等账号/系统内容；不铺整块客户看板 |
| P0-14 | 经营反馈归位到工作台 | 业务模式用户有展示页或客户动作数据 | 打开工作台 | 可从工作台进入对应反馈中心；不同模式前台命名分别为分享效果、客户看板/看房客户、接龙看板/买家记录、咨询看板/预约记录 |
| P0-15 | 展示页效果入口保留 | 已有已发布展示页 | 打开展示页列表或展示页详情 | 仍能进入单个展示页效果；不因客户看板迁移而丢失详情入口 |
| P0-16 | 单条资料互动入口保留 | 已有客户互动的资料 | 打开资料详情 | 仍能进入该资料的客户互动/效果入口；房源、商品、服务等按模式显示合适前台文案 |
| P0-17 | 资料库降噪 | 有多类型资料 | 打开“资料”Tab | 资料库聚焦单条资料搜索、筛选、编辑、分享、加入合集；不再承担经营看板主入口和全部创建入口集合 |
| P0-18 | 资料卡核心动作可用 | 有任意资料 | 打开资料库卡片或资料详情 | 可编辑、分享/发给客户、加入合集；按钮不挤压主要信息 |
| P0-19 | 合集页一期可进入 | 点击底部“合集” | 打开合集页 | 页面可正常打开；有清晰空态或轻版入口，说明合集是“把多条资料打包成可分享资料包” |
| P0-20 | 合集创建方向清楚 | 合集页为空或有入口 | 查看合集页创建入口 | 至少能看到普通资料包、房源推荐合集、服务案例合集、团购合集的创建方向或说明 |
| P0-21 | 我的页设置可修改模式 | 已登录用户 | 进入“我的”页设置或常用工作台入口 | 可以修改常用工作台；修改后首页和工作台内容同步变化 |
| P0-22 | 模式切换不删除资料 | 已有多类型资料 | 切换任意模式后查看资料库 | 已保存资料不丢失、不改变归属；只是首页、工作台、默认筛选和文案变化 |
| P0-23 | 业务识别提示不强迫切换 | 创建或整理出房源/商品/服务资料 | 查看类型识别后的提示 | 提示用户可切换到更合适工作台，但必须提供继续当前工作台的选项；不能强制改变身份 |
| P0-24 | 更多工具保留非当前模式功能 | 任一业务模式 | 打开首页或工作台更多工具 | 非当前模式功能不在首页平铺，但可从“更多工具”进入，不被彻底屏蔽 |
| P0-25 | 路由无阻断 | 小程序注册最新页面 | 逐个点击 Tabbar 和模式快捷入口 | 不出现页面不存在、白屏、死循环跳转或首页数据加载失败 |
| P0-26 | 空数据可用 | 新用户无资料、无合集、无客户动作 | 分别查看首页、资料、合集、工作台 | 所有页面有合理空态和创建引导，不出现空白页、报错页或假数据 |
| P0-27 | 权限和隐私不倒退 | 普通访客或非 owner | 尝试访问 owner 工作台/看板数据 | 普通访客不能看到 owner 后台统计；工作台迁移不破坏原有数据隔离 |

## 4. P1 测试项

| 编号 | 测试项 | 验收标准 |
| --- | --- | --- |
| P1-01 | 模式选择卡片文案准确 | 4 个模式卡片文案与开发文档一致，能让用户理解适用场景 |

| P1-05 | 日常资料台反馈命名 | 日常资料台只使用分享效果、最近分享、资料包浏览等词，不出现客户看板 |

| P1-09 | 首页最近成果可点击 | 最近资料、最近资料包、最近分享页点击后能进入对应页面或详情 |

| P1-11 | 资料库默认筛选随模式变化 | 切换到房源/团购/服务模式后，资料页默认筛选或推荐更贴近当前模式，但仍能查看全部资料 |
| P1-12 | 合集空态按模式辅助推荐 | 日常、房源、团购、服务模式下，合集页空态或创建入口能给出对应资料包方向 |

| P1-14 | UI 文本居中 | Tabbar、模式卡片、快捷入口、状态标签、底部按钮文字上下左右居中，不出现文字偏上、偏下或拆行 |
| P1-15 | iPad 和大屏布局不变形 | iPad、大屏手机、普通手机下首页卡片、Tabbar、入口按钮不重叠、不截断、不过度拉伸 |
| P1-16 | 切换反馈即时清楚 | 切换模式后有明确反馈，用户能知道当前已切到哪个工作台 |

| P1-18 | 旧入口迁移有过渡 | 旧客户看板入口、旧访客线索入口如果仍存在，应跳到新工作台位置或给出清晰过渡，不出现死入口 |

## 6. 自动化测试建议

### 后端测试

如果 `workspaceMode` 需要后端持久化，必须覆盖：

- 创建/更新用户常用工作台模式。
- 非法模式值拒绝或兜底为 `notes`。
- 切换模式不删除资料、不改资料 owner。
- 用户只能修改自己的常用工作台模式。
- mock 登录、真实登录返回用户信息中包含当前模式。

如果一期只做前端本地偏好，也必须在自测报告中明确说明“当前未做后端持久化”。

### 小程序静态检查

必须执行：

```text
find miniprogram -name '*.js' -print0 | xargs -0 -n 1 node --check
```

必须执行 JSON 解析：

```text
node -e "递归解析 miniprogram 下所有 .json"
```

必须执行：

```text
git diff --check
```

建议增加静态扫描：

- `app.json` 中 Tabbar 和页面注册完整。
- `workspaceMode` 只出现允许值：`notes/property/groupbuy/service`。
- 前台文案中日常资料台不出现 `客户 / 线索 / SCRM / 接龙 / 看房 / 买家`。
- 页面核心尺寸尽量使用 `rpx`，避免核心布局混用 `px`。

### 小程序逻辑测试

建议覆盖：

- 清空模式后进入首页，展示首次选择页。
- 选择 4 种模式后，首页配置输出不同模块。
- 二次进入读取已保存模式。
- 首页顶部切换模式后，资料、合集、工作台同步变化。
- 我的页修改模式后，首页同步变化。
- 业务识别提示点击“继续当前模式”和“切换模式”两种分支。
- 更多工具入口能进入非当前模式功能。

## 7. 真机回归清单

1. 删除本机小程序缓存或使用新测试用户打开小程序。
2. 确认首次进入出现“你想先整理哪类资料？”。
3. 依次选择日常资料台、房源工作台、团购工作台、服务工作台，记录首页变化。

5. 在房源工作台确认能看到房源、看房客户、预约看房、房源效果等业务入口。
6. 在团购工作台确认能看到商品、团购、接龙、买家、待处理订单/接龙。
7. 在服务工作台确认能看到电子名片、服务方案、咨询客户、预约记录。
8. 点击底部 5 个 Tab，确认页面名称和内容职责正确。
9. 打开“资料”Tab，确认聚焦单条资料管理，不再塞满经营入口。
10. 打开“合集”Tab，确认轻版入口和空态清晰。
11. 打开“工作台”Tab，确认内容随模式变化。
12. 打开“我的”Tab，确认客户看板不再铺在这里。
13. 从首页顶部切换模式，确认不会丢失资料。
14. 从“我的”页设置切换模式，确认首页和工作台同步变化。
15. 创建或整理一条房源/商品/服务资料，确认业务识别提示允许切换也允许继续当前模式。
