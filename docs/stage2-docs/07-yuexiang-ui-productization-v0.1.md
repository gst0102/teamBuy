# 资料整理助手 v0.1 上线前 UI 产品化改版开发文档

## 1. 改版目标

本次改版不是重做业务系统，而是在当前 `teamBuy` 已完成的企业微信导入、卡片、素材库、浏览统计、实名接龙、一键复用基础上，做「资料整理助手」上线前 UI 产品化包装。

对外统一表达：

```text
资料整理助手｜微信内容资源助手
快速整理微信内容，生成可分享的资源卡片。
```

v0.1 核心目标：

- 把开发联调版页面改成可演示、可上线、用户一眼能懂的产品页面。
- 先复用现有接口和数据，不引入支付、提现、复杂 CRM、订单系统等高风险模块。
- 保持企业微信真实联调优先级，UI 改版不能阻断当前 `sync_msg` 权限问题排查。

## 2. 页面范围

### 2.1 本次必须落地

| 页面 | 路径 | 说明 |
|---|---|---|
| 首页 | `pages/home/index` | 产品定位、数据概览、快捷入口、谁看过我、今日热门资源、邀请入口占位 |
| 资源库 | `pages/library/index` | 搜索、分类 chip、标签视觉、资源卡片、访问记录入口 |
| 添加 | `pages/resource-create/index` | 手动快速入库、上传素材、填写资料、保存到资源库 |
| 待认领导入 | `pages/imports/index` | 外部企业微信客服导入后的结果和待认领列表，不作为小程序内发送入口 |
| 访问记录 | `pages/visits/index` | 按资源聚合访客行为、高意向提醒、访问统计 |
| 我的 | `pages/profile/index` | 用户信息、资源数、会员入口占位、设置入口 |

### 2.2 本次保留但不重做

- `pages/card-edit/index`：继续作为卡片编辑页。
- `pages/card-view/index`：继续作为分享查看页。
- `pages/manager/index`：继续作为单资源管理和一键复用页。
- `pages/login/index`：继续作为 mock 登录入口，登录成功后进入首页。

## 3. tabBar 结构

```text
首页       -> pages/home/index
资源库     -> pages/library/index
添加       -> pages/resource-create/index
访问记录   -> pages/visits/index
我的       -> pages/profile/index
```

底部 tabBar 只承担主导航，不在 v0.1 中实现自定义凸起中间按钮。中间加号定位为「添加 / 快速入库」，不在小程序内提供「发给客服」操作入口。

## 4. 数据复用策略

### 4.1 现有接口

| 数据 | 现有接口 | 用途 |
|---|---|---|
| 资源列表 | `GET /api/cards` | 首页资源总数、资源库列表、热门资源 |
| 资源统计 | `GET /api/cards/{id}/stats` 或 `cards[].stats` | PV/UV、登录访客、匿名访问、接龙数 |
| 待认领导入 | `GET /api/imports/pending` | 外部导入后的待认领列表 |
| 导入通知 | `GET /api/wecom/notifications` | 外部导入结果 |
| mock 导入 | `POST /api/wecom/mock-sync` | 本地联调生成导入批次，不在小程序用户界面暴露 |
| 认领导入 | `POST /api/imports/{id}/claim` | 认领后进入编辑页 |

### 4.2 前端聚合规则

- 首页资源总数：`cards.length`。
- 访问人数：累加每张卡片 `stats.uv`。
- 今日访问：当前没有真实分日接口，v0.1 以总 PV 做展示，不写「真实今日」承诺。
- 谁看过我：合并 `stats.loggedInViewers`，只展示登录访客，不展示匿名身份。
- 今日热门资源：按 `stats.pv` 倒序取前 4 条。
- 高意向提醒：用简单前端规则标记，`pv >= 3` 或 `relayCount > 0` 或登录访客数较多。

## 5. 不做范围

v0.1 不实现以下真实业务：

- 微信支付
- 现金邀请奖励
- 提现 / 兑换
- 完整会员权益限制
- 完整 CRM 客户管理
- 团购订单系统
- 预约看房系统
- AI 智能整理真实调用
- 真正收藏、分享、下载行为统计接口

没有真实后端字段的收藏数、分享数、会员状态、邀请奖励，只能做 UI 占位或弱化展示，不伪造真实业务数据。

## 6. 隐私与合规

- 匿名访客只计入 PV/UV，不展示身份。
- 首页和访问记录页只展示后端已返回的 `loggedInViewers`。
- 手机号、地址等接龙敏感字段只能在拥有者管理页展示，不出现在首页、资源库和全局访问记录页。
- 「视频」只表示视频素材或视频笔记，不表达影视资源下载、片源推送或版权内容分发。

## 7. 验收清单

- 登录后进入首页。
- tabBar 可切换首页、资源库、添加、访问记录、我的。
- 首页「快速入库」进入添加资源页。
- 首页「我的资源库」进入资源库页。
- 资源库搜索仍调用现有 `keyword` 参数。
- 资源卡片可进入编辑页、查看页或管理页。
- 待认领导入仍可展示和认领。
- 小程序用户界面不出现「发给客服」「立即发给客服」「去发给客服」入口文案。
- 卡片编辑保存不受影响。
- 卡片发布查看不受影响。
- 浏览统计仍区分登录用户和匿名用户。
- 实名接龙、删除无效接龙、标记已跟进不受影响。
- 一键复用仍生成新卡片，不污染原卡片统计。
