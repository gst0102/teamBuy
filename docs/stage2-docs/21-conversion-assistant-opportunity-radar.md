# 成交辅助系统 V1：客户雷达、机会提醒与身份隔离

更新时间：2026-06-27

## 1. 目标

产品从“资料整理助手”升级为“私域资料成交助手”：

```text
资料整理 -> 生成可追踪成交页 -> 客户访问 -> 系统判断机会 -> 用户及时跟进
```

本期只做小程序内提醒和高亮，不做微信订阅消息、企业微信主动推送或自动回小程序卡片。

核心演示效果：

- 用户首页看到“今日成交机会”，而不是普通资料统计。
- 客户打开公开资料页后，发布者后台看到客户雷达、意向解释、跟进建议和可复制话术。
- 客户页仍然只是公开资料展示，不展示“高意向”“被分析”“跟进建议”等后台信息。

## 2. 身份与页面隔离

三种访问视角：

| 视角 | 能看什么 | 不能看什么 |
| --- | --- | --- |
| Owner / 发布者 | 首页机会、客户雷达、客户看板、跟进建议、私密字段 | 不适用 |
| Viewer / 客户 | 公开资料页、公开合集页、公开联系方式和转化按钮 | 客户雷达、统计、跟进建议、客户列表、私密字段 |
| Peer / 同行或上游 | 与客户相同的公开页，可生成同款 | 原发布者私密上游联系人、客户池 |

硬规则：

- 当前登录用户等于资源 `ownerUserId`，才允许进入 owner 管理视角。
- 当前登录用户不等于资源 `ownerUserId`，只能进入公开 viewer 视角。
- 未登录或匿名，只能进入公开 viewer 视角。
- 不能靠前端入口隐藏保护权限；后端私有接口必须校验 `requesterUserId == ownerUserId`。

## 3. 数据与接口

继续复用现有数据底座：

- `ShowcaseEvent`：展示页打开、资料点击、电话、复制微信、分享。
- `ViewEvent`：单条资料页访问。
- `CustomerAction`：留资、预约、咨询、下单、接龙等客户动作。
- `LeadReminder`：待跟进、客户资料和跟进记录。

访问事件增加可选行为字段：

- `sessionId`
- `durationSeconds`
- `maxScrollPercent`
- `focusSections`

`focusSections` 使用通用板块名，例如：

```text
价格/优惠、图片/户型、案例/成果、FAQ/保障、联系方式、地址/位置、商品规格、课程内容
```

`GET /api/dashboard/business` 只允许 owner 调用，并新增：

- `opportunitySummary`：今日高意向、待跟进、今日访客、最热资料、机会数。
- `opportunityAlerts`：机会提醒列表。
- `radarProfiles`：客户雷达列表。
- `contentInsights`：资料页优化建议。
- `revivalAlerts`：沉默后重新打开的机会复活提醒。

公开页接口只接收行为上报，不返回判断结果。

## 4. 规则引擎 V1

第一版不用大模型，使用规则引擎生成判断和话术。

高意向：

- 有电话、微信、预约、留言、下单、接龙等明确动作。
- 同一客户多次打开同一资料。
- 停留超过 90 秒，且重点看了价格、优惠、联系方式或 FAQ。
- 沉默 3 天以上后重新打开。

中意向：

- 停留超过 30 秒。
- 点击多条资料。
- 打开合集后进入单条资料。
- 重复查看但没有咨询动作。

低意向：

- 只打开一次，停留很短，未点击关键内容。

输出内容：

- 意向等级：高 / 中 / 低。
- 意图解释：例如“重点看了价格，可能正在比较预算”。
- 跟进建议：例如“建议 30 分钟内跟进”。
- 可复制话术：例如“刚看到你在看价格，我帮你把优惠后实际到手价整理一下，要不要我发你？”

## 5. 小程序改造

首页：

- 保留企业微信房源助手入口。
- 房源工作台的“今日概览”升级为“今日成交机会”。
- 四个指标优先展示：高意向、待跟进、今日访客、最热资料。
- 展示 1-3 条最重要机会提醒。

客户看板：

- 首屏升级为“客户雷达 / 今日成交机会”。
- 优先联系队列展示意向等级、原因、建议动作和可复制话术。
- 继续保留客户 / 同行 / 上游筛选。

资料效果：

- 增加资料优化建议，例如：
  - 打开多但咨询少，建议提前联系方式。
  - 价格区退出多，建议补优惠说明。
  - 案例区停留长，建议强化案例和客户反馈。
  - FAQ 浏览多，建议把保障说明前置。

客户公开页：

- 只做公开展示和行为上报。
- 不显示系统判断、跟进建议、客户雷达或访问统计。
- 不请求 dashboard、lead、私有 note 接口。

## 6. 验收标准

P0：

- 非 owner 请求 dashboard 返回 403。
- 公开资料页和公开合集页不返回私密字段、雷达、建议或客户列表。
- 公开页行为上报能记录停留、滚动和重点板块。
- owner 首页能看到今日机会提醒。
- owner 客户看板能看到客户雷达和跟进建议。
- 匿名访客不包装成实名客户。
- 同行 / 上游不进入客户待跟进主池。

P1：

- 沉默后重新打开能生成机会复活提醒。
- 资料效果页能展示优化建议。
- 机会提醒提供可复制跟进话术。

P2：

- 接入订阅消息或企业微信外部提醒。
- 使用大模型生成更自然的话术。
- 一键生成客户专属对比资料。
