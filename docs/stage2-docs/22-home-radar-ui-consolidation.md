# 首页与客户雷达 UI 收敛开发文档

## Summary

- 首页从“资料整理入口集合”收敛为“今日成交机会工作台”。
- 客户相关能力统一进入“客户雷达”，不再让首页、反馈页、客户看板、访客页同时承载客户判断。
- 客户雷达不是普通数据看板，而是成交辅助页：谁值得跟、为什么值得跟、客户在纠结什么、下一步发什么。
- 底部 tab 中“反馈”升级为“雷达”。

## 1. 首页目标

- 第一屏优先展示今日成交机会，而不是入口堆叠。
- 首页只保留三个主任务：
  - 看今天最值得跟的客户。
  - 把房源发给助手。
  - 进入客户雷达。
- “最近成果”保留为轻量复盘，不成为首页主角。

## 2. 首页信息架构

### 2.1 今日成交机会

- 标题：`今日成交机会`
- 副标题：`先看谁值得跟、为什么跟、怎么开口。`
- 优先展示 1 条最高优先级机会：
  - 客户名称或匿名访客。
  - 看过的房源/资料。
  - 意向原因。
  - 建议动作。
  - 复制话术按钮。
- 无数据时展示空状态：
  - `还没有新的机会，把房源发给客户后，系统会自动盯访问、停留和咨询。`

### 2.2 指标

四个紧凑指标：

- 高意向
- 待跟进
- 今日访客
- 最热房源

指标只作为扫描辅助，不使用彩色大按钮堆叠。

### 2.3 把房源发给助手

只保留两个核心动作：

- 添加房源助手
- 转发群房源

不再在首页同时放“生成同款、房源合集、客户反馈”等多个同级入口。

### 2.4 统一客户入口

首页只提供一个客户相关入口：

- 标题：`客户雷达`
- 副标题：`客户、访客、跟进建议都在这里。`
- 展示新提醒数量。
- 点击进入底部 tab 的雷达页。

## 3. 客户雷达目标

- 雷达页是客户相关的唯一主入口。
- 默认视图为 `待跟进`。
- 页面要直接回答：
  - 谁值得联系。
  - 为什么系统推荐。
  - 客户画像是什么。
  - 下一步怎么开口。
  - 是否需要生成对比合集或优化资料。

## 4. 雷达页信息架构

### 4.1 顶部分段

- 待跟进
- 访客
- 资料优化

### 4.2 今日优先跟进

四个指标：

- 高意向
- 待跟进
- 复活机会
- 同行过滤

### 4.3 客户卡

每张客户卡必须包含：

- 客户名或匿名访客。
- 意向等级。
- 当前状态：高意向、持续关注、沉默复活、只是看看。
- 关注点标签：价格敏感、位置优先、关注联系方式、需要信任、想马上入住。
- 行为证据：打开次数、看过资料、停留或重点板块。
- 建议动作：复制话术、查看轨迹、标记已联系、生成对比建议。

### 4.4 客户画像规则

客户画像由五部分组成：

```text
客户画像 = 身份判断 + 意向阶段 + 关注点 + 行为证据 + 下一步动作
```

标签分三层：

- 身份标签：客户、同行、上游、匿名访客。
- 意向标签：高意向、持续关注、沉默复活、只是看看。
- 关注点标签：价格敏感、位置优先、联系方式、案例/信任、保障/FAQ。

标签必须能解释证据，不做无依据的“AI 猜测”。

### 4.5 系统建议动作

系统建议动作不是泛泛建议，而是可执行动作：

- 发优惠说明。
- 发送案例或客户反馈。
- 生成同价位对比合集。
- 把联系方式提前。
- 补充保障/押金/月付/可短租说明。

### 4.6 资料优化

资料优化页展示：

- 哪个房源打开多但咨询少。
- 哪个板块停留多。
- 可能流失点。
- 建议如何改。

示例：

- `碧桂园城市之光：价格区停留多，建议补充押金/月付/优惠说明。`
- `万润时光里：打开多咨询少，建议把联系方式提前。`

## 5. UI 原则

- 页面不做入口堆叠。
- 首页少即是多，只保留最关键的成交动作。
- 雷达页要像销售助理，不像报表后台。
- 按钮、标签、分段控制必须使用 flex 居中。
- 手机端优先避免固定浮层遮挡主操作。
- 客户判断只在 owner 私有接口中展示，公开资料页不得显示任何雷达判断。

## 6. 本期实现范围

- 首页 UI 重构。
- 底部 tab 文案“反馈”改“雷达”。
- `pages/visits` 重构为雷达入口页。
- 优先复用现有 `/api/dashboard/business` 字段：
  - `opportunitySummary`
  - `opportunityAlerts`
  - `radarProfiles`
  - `contentInsights`
  - `revivalAlerts`
- 字段不存在时，使用现有本地资源/访客数据做空状态和基础兜底。

## 7. 暂不做

- 不做外部订阅消息推送。
- 不做大模型判断。
- 不做完整一键生成对比合集链路，只显示建议入口。
- 不把匿名访客包装成实名客户。
