# 资料、合集、雷达三页销售助理闭环 V1

## Summary

- 底部仍叫“资料”，不改成“资源”。
- 三个页面分工：
  - 资料：管理单条资料，直接发客户。
  - 合集：把多条资料打包发客户。
  - 雷达：看客户反馈和跟进建议。
- 产品心智继续围绕“资料发出去，机会看得见”。
- 资料和合集都必须能“发客户”，不强制所有资料先做合集。
- 本期先用前端轻规则呈现“发客户后的状态追踪”，不新增后端正式状态表。

## 1. 页面定位

### 资料页

定位文案：

> 管理单条资料，直接发客户。

资料页只负责单条资料：

- 搜索、筛选、编辑、删除。
- 单条资料直接发客户。
- 加入合集。
- 显示创建时间。
- 显示轻量反馈和发出状态。

资料页不要展开客户列表和复杂雷达判断，只给轻量入口。

### 合集页

定位文案：

> 把多条资料打包发客户。

合集页负责可分享资料包：

- 多条资料组合。
- 预览、编辑、发客户。
- 显示创建时间、发布状态、包含资料数。
- 显示打开、访客、咨询。
- 显示发出状态追踪。

### 雷达页

定位文案：

> 看客户反馈和跟进建议。

雷达页负责销售助理判断：

- 谁值得跟。
- 为什么跟。
- 下一句怎么说。
- 客户画像标签。
- 资料优化建议。
- 生成对比合集建议。

## 2. 主按钮语义

资料页和合集页主按钮统一叫：

> 发客户

含义：

- 不是普通分享。
- 是生成或打开可追踪客户页，并发给客户。
- 客户打开后进入雷达。

资料页：

- 主按钮：发客户。
- 次按钮：编辑 / 合集 / 更多。
- 有客户动作时轻入口：去雷达。

合集页：

- 主按钮：发客户。
- 次按钮：编辑 / 更多。
- 已发布合集才能直接发客户。
- 草稿合集先编辑发布。

## 3. 发客户后的状态追踪

资料和合集发出去后，不要仍像普通静态卡片。

状态用浅色条呈现：

- 等待客户打开。
- 客户已打开。
- 客户重复查看。
- 建议跟进。
- 草稿待发。

V1 规则：

- 没有打开和访客：等待客户打开。
- 有打开或访客：客户已打开。
- 多访客或多次打开：客户重复查看。
- 有咨询、留言、预约、接龙、待跟进：建议跟进。
- 合集未发布：草稿待发。

状态条示例：

- `等待客户打开`：点发客户后，客户反馈会进雷达。
- `客户已打开`：可以观察是否继续浏览。
- `客户重复查看`：适合补一句对比或优惠。
- `建议跟进 2`：客户有动作，去雷达看原因。
- `草稿待发`：发布后即可发客户并追踪反馈。

## 4. 三页闭环

完整链路：

```text
资料
  -> 发客户
  -> 客户打开
  -> 雷达给判断和话术

资料
  -> 加入合集
  -> 合集发客户
  -> 客户连续看多条
  -> 雷达建议生成对比合集

雷达
  -> 打开来源资料/合集
  -> 优化资料
  -> 再次发客户
```

## 5. 后续酷功能池

### 资料页

- 发前体检：
  - 缺联系方式。
  - 价格信息不清。
  - 标题不够像客户语言。
  - 图片或案例不足。
- 自动生成开场白：
  - “这套我帮你整理成一页了，你先看价格和位置。”
- 适合发给谁：
  - 预算敏感。
  - 位置优先。
  - 看案例客户。
  - 想快速决策客户。

### 合集页

- 自动推荐合集：
  - 多个客户看了同价位房源。
  - 多个买家对比类似商品。
  - 服务客户反复看案例。
- 客户专属合集：
  - 给王女士的三套推荐。
  - 给李先生的服务方案对比。
- 合集成交力评分：
  - 打开多咨询少。
  - 标题弱。
  - 封面弱。
  - 联系方式靠后。

### 雷达页

- 客户画像标签：
  - 价格敏感。
  - 位置优先。
  - 看联系方式。
  - 看案例。
  - 沉默复活。
  - 高概率同行。
- 下一句话建议。
- 最佳跟进窗口。
- 客户温度变化。
- 错过提醒。
- 今日跟进任务。

## 8. P1 收口：规则版已落地

### 8.1 资料发前体检

资料卡新增 `salesCheck`：

- 缺联系方式。
- 价格不清。
- 缺图片。
- 标题偏短。
- 发前体检通过。

展示方式：

- 资料卡内用浅色提示条展示。
- 不是阻断发布，只提醒用户补强。

### 8.2 下一句话建议

雷达话术根据标签生成：

- 价格/优惠：建议发同价位对比。
- 位置/地址：建议补附近可选方案。
- 联系方式：建议立即确认细节。
- 案例/保障：建议发案例和保障说明。
- 沉默复活：建议发最新情况。
- 正在比较/反复查看：建议发相近资料对比。

### 8.3 客户画像标签增强

雷达画像标签补充：

- 价格敏感。
- 位置优先。
- 联系意向。
- 关注保障。
- 需要信任。
- 沉默复活。
- 反复查看。
- 正在比较。
- 有咨询动作。
- 疑似同行。
- 疑似上游。
- 多次触达。

### 8.4 自动推荐合集入口

雷达“生成对比合集建议”不再只是 toast：

- 跳转到合集创建页。
- 带上 `method=radar_compare`。
- 如果有来源资料，带上 `noteId` 预选。
- 合集创建页展示“来自雷达建议”提示。

### 8.5 雷达到资料/合集反向跳转

- 雷达客户卡新增“打开来源”。
- 资料优化建议按钮可跳回来源资料。
- 第一版优先打开 `note-preview`，失败再走资源卡兜底。

### 8.6 资料/合集状态过滤

资料页新增状态筛选：

- 全部。
- 待整理。
- 已发客户。
- 有反馈。

合集页新增状态筛选：

- 全部。
- 草稿。
- 已发布。
- 有反馈。

## 9. P0 收口：真实发客户链路

当前已把“发客户”从按钮文案推进为真实事件链路。

已完成：

- 资料页卡片的“发客户”改为真实分享按钮。
- 单条资料分享时生成 `shareId`。
- 单条资料分享时通过 `/api/notes/{noteId}/view` 记录 `eventType=share`。
- 单条资料分享路径携带：
  - `sid`
  - `from`
  - `src`
  - `ref`
- 客户打开单条资料页时，浏览事件会回传 `shareId/shareFromUserId/scene/referrer`。
- `ViewEvent` 增加：
  - `shareId`
  - `shareFromUserId`
  - `scene`
  - `referrer`
- `view_events` 增加对应列和 `idx_view_events_share` 索引。
- 资料统计新增：
  - `shareCount`
  - `latestShareAt`
  - `topShareId`
- `share` 事件不计入 PV/UV。
- owner 自己打开单条资料不计入 PV/UV。
- owner 自己打开合集不计入合集 PV/UV。
- 资料卡状态支持真实 `shareCount`：
  - 未发：等待客户打开。
  - 已发未打开：已发出，等待打开。
  - 客户打开：客户已打开。
  - 重复查看：客户重复查看。
  - 有动作：建议跟进。

补强完成：

- 在资料页点“发客户”后，本地卡片即时显示“已发出，等待打开”。
- 在合集页点“发客户”后，本地合集即时显示“已发出，等待打开”。
- 资料和合集卡片下方新增裂变提示：
  - “发给客户后可看反馈；对方也能生成同款，帮你带来更多传播。”
- 资料公开页和合集公开页的转发标题统一为客户友好口径：
  - “xxx｜点开查看完整资料”
- “生成同款”主要放在公开页和列表提示里承接，不直接把客户收到的分享标题写得过度营销。
- 资料页“发前体检”提示支持点击直达编辑。

仍可增强：

- 做单独的 `send_records` 或 `share_records` 表，沉淀更完整的发送对象和发送渠道。
- 在雷达里按 `shareId` 下钻查看一次发送带来的客户行为。
- 发送后按微信会话、朋友圈、群、私聊等来源做渠道效果对比。
