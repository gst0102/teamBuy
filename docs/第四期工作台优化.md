## 1. 项目背景与目标

项目正式产品名是“资料整理助手”。

核心目标：

- 帮用户把微信、企业微信、手动输入、链接、图片等零散资料整理成可检索、可复用、可分享的资料资产。
- 稳定基座负责资料入库、用户身份、企业微信接入、笔记库、专题、合集、展示页、反馈统计等通用能力。
- 具体场景能力按工作台或插件扩展，避免把所有用户都推入复杂 SCRM。

当前前台工作台固定为四类：

- 日常资料台：笔记、图片、链接、普通资料整理，重点是资料库、专题、日常合集和分享反馈。
- 房源工作台：房源资料、房源合集、客户看房反馈、待跟进。
- 团购/商品工作台：商品资料、商品合集、接龙/下单名单、订单处理。
- 服务工作台：电子名片、服务方案、案例合集、咨询/预约反馈。

## 2. 当前阶段目标

本阶段主要目标是把四个工作台从“能打开”推进到“入口、出口、命名、数据范围基本清楚”：

- 首页和底部 Tab 根据当前工作台展示不同内容。
- 资料库按当前工作台隔离，不让日常用户看到房源、商品、服务资料。
- 反馈页按当前工作台隔离，不默认展示四个业务切换。
- 合集按场景命名并隔离：日常合集、房源合集、商品合集、案例合集。
- 内部整理统一叫“专题”，外部分享统一叫“合集”。
- 普通资料不默认 SCRM 化，留言、咨询、接龙作为后续插件能力占位。
