# teamBuy Miniprogram

本目录是原生微信小程序 MVP 骨架，默认联调本地 FastAPI。

## 页面范围

- 登录页：mock 登录
- 待认领导入页：触发本地 mock 企业微信导入并认领
- 素材库页：查看自己的卡片与摘要
- 卡片编辑页：保存和发布草稿
- 卡片查看页：浏览、拨号、复制、实名接龙
- 团长管理页：看浏览记录、接龙名单、删除/跟进、一键复用

## 本地联调

1. 先启动后端：`uvicorn app.main:app --reload`
2. 用微信开发者工具打开 `miniprogram/`
3. 若需要真机调试，把 `app.js` 里的 `apiBaseUrl` 改为局域网地址

## 注意

- 当前为本地阶段，登录、企业微信导入、素材转存都走 mock。
- 真实 AppID、企业微信回调和对象存储接入留到后续阶段替换。
