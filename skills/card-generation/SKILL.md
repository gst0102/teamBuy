# 卡片生成 Skill

## 1. 使用场景

当任务涉及以下内容时，必须读取并遵守本 Skill：

- 导入内容生成卡片草稿
- 卡片字段模型
- 规则解析
- 大模型兜底解析
- 卡片编辑和保存
- 字段展示开关
- 一键复用

## 2. 卡片字段

卡片采用通用可选字段，不写死为房产或团购专用字段。

首版字段包括：

- 标题
- 封面图
- 图文详情
- 视频
- 项目名
- 位置
- 联系电话
- 接龙说明
- 原始来源链接

## 3. 生成规则

默认规则：

- 第一段文本优先作为标题候选。
- 第一张图片优先作为封面候选。
- 其余图片进入图集或详情图区。
- 链接消息保留来源 URL、标题、描述、缩略图。
- 其余文本合并为图文详情正文。
- 识别到手机号时填入联系电话候选。
- 识别到位置消息时填入位置候选。
- 视频消息进入视频区。

## 4. 大模型使用边界

解析策略是规则优先 + 大模型兜底。

大模型只做：

- 文本清洗与重组
- 从正文抽取候选字段
- 补全标题、项目名、位置、联系电话等候选值

不要让大模型跳过原始消息结构直接生成完全黑盒结果。

## 5. 一键复用

一键复用定义为复制整张历史卡片重新发起。

要求：

- 新卡片继承原字段内容。
- 新卡片生成独立 ID。
- 新卡片浏览数据重新统计。
- 新卡片接龙数据重新统计。
- 不得覆盖原卡片历史数据。
