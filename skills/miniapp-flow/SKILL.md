# 小程序流程 Skill

## 1. 使用场景

当任务涉及以下内容时，必须读取并遵守本 Skill：

- 原生微信小程序页面设计
- 微信登录
- 待认领导入
- 素材库
- 卡片编辑
- 卡片查看
- 群分享
- 电话直拨
- 字段复制
- 实名接龙
- 团长管理

## 2. 页面范围

首版页面包括：

- 登录页
- 待认领导入页
- 素材库页
- 卡片编辑页
- 卡片查看页
- 接龙提交页或弹层
- 团长管理页
- 浏览统计页或统计区域

## 3. 查看和分享规则

- 卡片必须能分享到微信群。
- 群用户打开卡片后可以查看所有已启用字段。
- 联系电话字段必须支持点击直拨。
- 关键字段必须支持复制。
- 未登录用户可以计入匿名浏览统计，但不能展示为实名浏览用户。

## 4. 接龙规则

- 接龙必须登录，不允许匿名。
- 默认使用微信头像和昵称。
- 团长可选附加字段：手机号、地址。
- 团长可以看到完整用户名字。
- 普通用户看到的名字必须脱敏，只显示前两个字，其余用 `*` 隐藏。

## 5. 团长管理规则

团长必须可以：

- 查看接龙名单
- 删除无效接龙
- 标记已跟进
- 查看浏览人数和浏览次数
- 查看已登录浏览用户列表

## 6. P0 禁止事项

- 不得把匿名浏览者展示为实名用户。
- 不得让普通用户看到未脱敏昵称。
- 不得让复用卡片覆盖原卡片统计数据。
- 不得把密钥、Token、AppSecret 写入前端。
