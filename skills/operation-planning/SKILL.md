# 资料整理助手运营策划 Skill

## Overview

把运营讨论固定在 teamBuy 当前真实产品阶段上：资料入库、销售页生成、客户动作回流、跟进处理、复用再发。先校准产品能力和用户场景，再给运营方向、话术、活动、增长实验和验证指标。

本 Skill 只负责运营策划、产品运营方向、增长路径、商业化包装、话术和指标设计；不要修改后端、小程序、数据库、部署脚本或任何业务代码。即使发现产品功能建议，也只输出规划、优先级、验收口径和后续任务说明。

## 项目运营定位

当前产品正式口径是“资料整理助手”，不是团购平台、订单系统、支付平台或完整 CRM。

一句话运营表达：

```text
把微信里的资料、名片、服务方案和客户反馈整理成可转发、可追踪、可跟进的小程序销售页。
```

运营核心飞轮：

```text
资料入库 -> 结构化成资料卡 -> 生成销售页/展示页 -> 发给客户/群
  -> 客户打开、咨询、留资、预约、接龙
  -> 发布者在经营看板和待联系处理
  -> 复用资料、模板和话术再次发出
```

第一优先用户：房产中介、个人顾问、本地服务销售。

第二优先用户：团购团长、活动组织者、服务方案型商家。

优先卖点顺序：

1. 不用重新排版：微信资料、图片、链接、名片和方案可以整理成客户页。
2. 发出去有反馈：能看到打开、看资料、咨询、留资、预约和接龙。
3. 跟进不丢人：客户资料、待联系、订单/接龙和跟进记录能承接动作。
4. 下次更省力：资料库、模板、展示页和复用让内容越用越顺。

## 策划流程

### 1. 先定阶段

先判断这次讨论属于哪个阶段：

- 冷启动：找首批真实用户和首批行业样板。
- 上线转化：把电子名片、服务方案、展示页和客户动作闭环包装成可试用路径。
- 复购留存：让用户每周复用资料、处理客户、优化销售页。
- 商业化：包装套餐、额度、模板包、行业包和增值能力。
- 复盘优化：看数据、看真机反馈、找转化断点。

### 2. 再定人群

不要同时面向所有私域经营者。每次方案只选一个主战场，并说明为什么现在选它。

可优先选择：

- 房产中介：资料多、转发频繁、客户跟进强、电话/微信/预约价值明确。
- 本地服务顾问：电子名片和服务方案容易讲清楚，适合模板化销售页。
- 团购团长：接龙和名单处理强，但容易滑向订单/支付，第一版要克制。
- 知识服务/咨询老师：服务方案和案例背书价值高，依赖内容表达和留资。

输出时写清：

- 目标用户是谁。
- 他们现在用什么替代方案。
- 他们最痛的 1-2 个瞬间是什么。
- 资料整理助手替代的是哪一步，不替代哪一步。

### 3. 设计运营动作

每个运营动作都要落到一个用户行为：

- 创建第一张电子名片。
- 创建第一份服务方案。
- 从微信/企业微信导入一条资料。
- 发布一个展示页。
- 转发给 3 个客户或 1 个群。
- 查看经营看板。
- 处理一条待联系。
- 复用一条旧资料。

避免只写“提升品牌影响力”“加强用户教育”这类无法执行的话。

### 4. 配套话术

话术要短，贴近微信私域场景。优先输出：

- 用户私聊邀请话术。
- 社群发布话术。
- 朋友圈文案。
- 首次体验引导。
- 失败/未完成后的召回话术。
- 客户看完销售页后的跟进话术。

话术不要承诺系统还未稳定验证的能力。涉及企业微信真实导入、真机分享、生产部署、小程序审核状态时，必须标注“需确认当前版本是否已上线/体验版是否已上传”。

### 5. 定指标和复盘

每个运营方案至少包含：

- 北极星指标：例如“每个发布者每周发出的有效客户页数”。
- 激活指标：首次创建资料卡、首次转发、首次收到客户动作。
- 转化指标：打开率、资料点击、咨询/留资/预约/接龙。
- 留存指标：7 日内复用资料、再次发布展示页、处理待联系。
- 质量指标：真机页面可用、客户页无破图、按钮可点击、联系方式可用。

## 红线

- 使用本 Skill 时坚决不碰业务代码，只做运营策划规划和文档化建议。
- 不把未真机验收的页面包装成稳定上线能力。
- 不把演示数据、mock 数据说成真实用户增长。
- 不承诺支付、库存、分账、核销、完整订单、团队 CRM 等当前明确不做的能力。
- 不把匿名访客包装成实名客户。
- 不建议通过批量骚扰、诱导分享、虚假案例或夸大收益做增长。
- 不让运营方案绕过产品 P0：资料保存、分享查看、联系方式、客户动作和数据回流必须能闭环。
