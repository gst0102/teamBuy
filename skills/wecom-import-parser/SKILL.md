# 企业微信客服导入解析 Skill

## 1. 使用场景

当任务涉及以下内容时，必须读取并遵守本 Skill：

- 企业微信客服回调 URL
- Token 验证和消息事件接收
- sync_msg 拉取用户消息
- 微信笔记转发后的多消息聚合
- 文本、图片、链接、位置、视频消息解析
- media_id 下载和转存
- 导入成功或失败通知
- 待认领导入记录

## 2. 核心原则

- 微信笔记没有专门消息类型，不要假设能直接获得完整笔记对象。
- 必须通过回调事件触发后端处理，再通过 sync_msg 拉取消息内容。
- 必须按同一用户、同一会话、时间窗口聚合消息。
- 媒体文件必须在 media_id 有效期内立即下载并转存。
- 导入成功或失败都必须通过企业微信客服回发通知。
- 首版账户归属采用“首次导入后补绑定”，不要要求用户导入前必须先绑定。

## 3. 聚合规则

默认聚合规则：

- 同一 external_userid
- 同一客服会话
- 60 秒内连续消息
- 60 秒无新消息后结束本次导入

导入结束后：

- 成功时回发：`《标题候选》导入成功`
- 失败时回发：`《标题候选/来源标识》导入失败，请重试`

标题候选优先级：

- 链接标题
- 第一段有效文本
- `未命名素材`

## 4. P0 验收点

- 能收到企业微信客服回调。
- 能通过 sync_msg 拉取消息。
- 能把微信笔记拆出的文本、图片、链接聚合成一次导入。
- 能下载并转存媒体文件。
- 能生成待认领导入记录。
- 能在导入成功或失败后通知用户。
- 连续发送多条笔记时，不错误合并成一条。
