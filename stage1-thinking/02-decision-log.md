# 阶段一决策记录

| 决策 | 选择 | 理由 | 是否可调整 |
|---|---|---|---|
| 产品核心方向 | 素材导入 + 卡片生成 + 查看统计 + 实名接龙 | 比团购交易系统更轻，更贴近用户真实痛点 | 可调整 |
| 首批目标用户 | 房产中介优先，团购团长其次 | 房产中介素材转发频繁，电话、位置、浏览、跟进价值明显 | 可调整 |
| 是否做收款 | 首版不做收款、订单、支付、分账 | 避免首版复杂度失控，先验证素材传播和接龙价值 | 可调整 |
| 主导入入口 | 企业微信客服 | 用户可直接转发微信笔记或链接，适合承接外部素材 | 不建议首版调整 |
| 辅助入口 | 小程序内手动新增和编辑 | 保证导入失败时用户仍能手动创建卡片 | 不建议调整 |
| 必须支持的导入来源 | 微信笔记 | 这是项目核心能力和最大差异点 | 不建议调整 |
| 链接支持优先级 | 小程序链接 > 公众号链接 > 普通网页链接 | 用户明确指定优先级 | 可调整 |
| 账户归属方式 | 首次导入后补绑定 | 用户先发内容给客服，系统暂存，用户登录小程序后认领 | 可调整 |
| 导入结束规则 | 60 秒无新消息自动结束 | 适合连续转发笔记或链接，减少用户额外操作 | 可调整 |
| 导入结果通知 | 企业微信客服回发导入成功或失败 | 用户需要知道导入是否完成，最好带标题 | 不建议调整 |
| 卡片模型 | 通用可选字段 | 不写死房产或团购字段，用户自行选择展示 | 不建议调整 |
| 接龙方式 | 必须登录，不允许匿名 | 需要头像昵称和后续管理 | 不建议调整 |
| 浏览统计口径 | 登录用户展示头像昵称，匿名用户只计入总量 | 未登录用户无法稳定展示身份 | 不建议调整 |
| 接龙附加字段 | 手机号、地址 | 首版只保留最常用字段，降低填写打扰 | 可调整 |
| 一键复用定义 | 复制整张历史卡片重新发起 | 新卡片独立统计浏览和接龙数据 | 不建议调整 |
| 技术栈 | 原生微信小程序 + FastAPI | 小程序贴合微信生态，Python 便于回调、解析和大模型接入 | 可调整 |
| 部署方式 | 腾讯云轻量或云服务器 | 便于接企业微信回调、异步任务、媒体转存和数据库 | 可调整 |
| 解析策略 | 规则优先 + 大模型兜底 | 稳定、可控、成本可控，同时保留复杂内容解析能力 | 不建议调整 |
