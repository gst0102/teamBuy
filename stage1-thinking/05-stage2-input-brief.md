# 阶段二输入摘要

## 项目名称

teamBuy

## 一句话定位

一个通过企业微信客服导入微信笔记和链接，自动生成可复用素材卡片，并支持微信群查看、统计和实名接龙的小程序工具。

## MVP 目标

验证用户是否愿意通过企业微信客服导入微信笔记或链接，自动生成可编辑卡片，并在微信群中完成查看、统计、接龙和素材复用闭环。

## 目标用户

第一优先用户是房产中介。

第二优先用户是团购团长。

## 核心功能

- 企业微信客服接收微信笔记和链接
- 后端回调和 sync_msg 拉取消息
- 微信笔记多消息聚合
- 卡片草稿生成
- 规则优先解析
- 大模型兜底解析
- 首次导入后补绑定
- 小程序登录
- 待认领导入记录
- 卡片编辑
- 卡片保存
- 卡片分享到微信群
- 卡片查看
- 电话直拨
- 字段复制
- 浏览人数和浏览次数统计
- 登录浏览用户列表
- 匿名浏览总量统计
- 实名接龙
- 手机号和地址可选字段
- 接龙名单管理
- 删除无效接龙
- 标记已跟进
- 素材库搜索
- 素材分类
- 一键复用整张历史卡片

## 页面和模块

- 登录页
- 待认领导入页
- 素材库页
- 卡片编辑页
- 卡片查看页
- 接龙提交页或弹层
- 团长管理页
- 浏览统计页或统计区域
- 企业微信回调模块
- 消息聚合模块
- 解析模块
- 媒体转存模块
- 卡片模块
- 浏览统计模块
- 接龙模块

## 资源需求

- 微信小程序 AppID
- 企业微信主体
- 企业微信客服账号
- 企业微信回调 Token、EncodingAESKey、Secret
- 腾讯云服务器
- 数据库
- 对象存储
- 大模型 API Key
- 微信客服官方文档
- 小程序客服接入文档
- 接收消息和事件文档
- 获取临时素材文档

## 技术约束

- 前端使用原生微信小程序
- 后端使用 FastAPI
- 部署使用腾讯云轻量或云服务器
- 后端必须可公网访问企业微信回调 URL
- 企业微信客服必须开启 API 管理模式
- 小程序和企业微信主体需要满足官方接入要求
- 媒体文件收到后必须及时转存
- 浏览用户列表只展示已登录用户
- 匿名用户只计入浏览总量
- 首版不做支付、订单、收款、分账

## 商业化

阶段一暂不实现商业化功能。

后续建议围绕导入能力、素材库存量、一键复用频率、活跃接龙数量、高级解析能力设计订阅。

原始设想包括免费层、月费 9.9 元、年费 99 元、推荐返佣。该方案进入二期再评估，不进入首版 P0。

## 验证指标

- 微信笔记导入成功率
- 链接导入成功率
- 导入生成卡片耗时
- 卡片编辑发布率
- 卡片分享率
- 卡片查看率
- 登录浏览用户占比
- 匿名浏览占比
- 接龙提交率
- 一键复用次数
- 发起人 7 日留存
- 单用户平均素材数
- 单卡片平均浏览人数
- 单卡片平均接龙人数

## 待确认问题

- 企业微信客服回调和 sync_msg 的实际消息结构需要用真实账号调试确认
- 微信笔记转发后图片、文本、链接、视频、位置的实际拆分方式需要实测
- 小程序链接能解析到哪些字段需要实测
- 大模型 API 供应商和成本预算需要确认
- 对象存储供应商和媒体访问权限需要确认
- 浏览统计是否需要防刷策略需要阶段二设计
- 接龙名单是否需要导出功能暂定为 P2
- 是否需要多客服分配暂定为 P2
